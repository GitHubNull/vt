# v1.0 正式版子路线图

> 阶段定位：正式发布。目标：MCP 服务、移动麦克风（桌面端配套）、隐私安全完善、双语言与深色主题。
> 发布标准（PRD 6.1）：第 5 章全部 P0 级非功能指标达标；目标应用兼容性测试全部通过。
>
> **SPEC 说明**：本阶段任务只列清单，详细 SPEC 在阶段启动前编写，存放于 `doc/specs/v1.0/`。任务编号段：`T-1001` 起。
>
> **移动端边界**：移动客户端仅 Android，为独立仓库 `vt-mobile`；本阶段本仓库只含**桌面端配套**任务，Android 端任务在 vt-mobile 仓库管理。

## 一、阶段范围（PRD 功能编号）

# v0.5 Beta 子路线图

> 阶段定位：公开测试。目标：程序员差异化能力（编程口令、场景感知、AI 模板）就绪。
> 发布标准（PRD 6.1）：NFR-A-02 ~ A-06 达标；终端安全保护通过专项测试。
>
> 本阶段任务编号段：`T-501` 起；每个任务的详细 SPEC 见 [doc/specs/v0.5/](../specs/v0.5/)。

## 一、阶段范围（PRD 功能编号）

| 模块 | 功能编号 |
| --- | --- |
| 编程 | F-CODE-01 场景规则、F-CODE-02 命名风格口令、F-CODE-03 符号口令、F-CODE-04 按键口令、F-CODE-05 终端安全保护、F-CODE-06 技术词库、F-CODE-08 中英混排规范 |
| 词典 | F-DICT-02 专有名词、F-DICT-03 导入导出 |
| AI | F-AI-01 提示词模板管理、F-AI-02 模板快捷键、F-AI-03 编程向内置模板、F-AI-05 超时降级、F-AI-06 AI 供应商管理、F-AI-07 模型列表管理、F-AI-08 连通性测试/拉取模型 |
| 统计 | F-STAT-01 使用统计 |
| 系统 | F-SYS-02 首次使用引导、F-SYS-03 快捷键冲突检测 |

## 三、发布验收清单（阶段启动时细化到各 SPEC）

- [ ] NFR-A-02 编程术语准确率 ≥90%（启用词库）
- [ ] NFR-A-03 中英混说整句正确率 ≥80%
- [ ] NFR-A-04 命名风格口令正确率 ≥95%
- [ ] NFR-A-05 符号口令误转换率 ≤1%
- [ ] NFR-A-06 按键口令误触发率 ≤0.5%
- [ ] 终端安全保护专项测试通过（NFR-S-05：任何口令/词典规则不得绕过）
- [ ] AI 外发首次确认与敏感信息打码可用

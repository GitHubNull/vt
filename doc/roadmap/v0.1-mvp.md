# v0.1 MVP 子路线图

> 阶段定位：内部试用。目标：核心语音输入链路在三个平台可用。
> 发布标准（PRD 6.1）：NFR-P-03（≤10 秒语音 P95 上屏 ≤800 ms）、NFR-A-01（普通话字准确率 ≥95%）达标。

## 一、阶段范围（PRD 功能编号）

| 模块 | 功能编号 |
| --- | --- |
| 语音输入 | F-INPUT-01 全局快捷键录音、F-INPUT-02 按住/切换模式、F-INPUT-03 本地离线识别、F-INPUT-04 光标处上屏、F-INPUT-05 录音悬浮球、F-INPUT-06 语音输入小窗、F-INPUT-07 取消录音、F-INPUT-09 无焦点兜底 |
| 词典 | F-DICT-01 替换词典 |
| 通用 | F-SET-01 界面语言/主题（浅色）、F-SET-02 文本输出选项、F-SET-03 录音环境、F-SET-05 系统与数据、F-SET-06 模型管理 |
| 关于 | F-ABOUT-01 版本与更新、F-ABOUT-02 导出日志、F-ABOUT-03 法律信息 |
| 系统 | F-SYS-01 托盘菜单 |

**明确不在本阶段**：F-INPUT-08 历史记录（v1.0）、编程模块与 AI（v0.5）、移动麦克风与 MCP（v1.0）、深色主题与英文界面（v1.0）。

## 四、发布验收清单

> 状态更新于 2026-10-10（T-001 ~ T-016 全部实现并提交）。标注说明：✅=已有机器验证证据；◐=代码级/参考值验证通过，待真机复核；⬜=需人工或基准机执行。

- [x] T-001 ~ T-016 全部 SPEC 验收标准通过（机器可验项：cargo fmt/clippy/test 101+4 通过、pnpm typecheck/lint/test 79 通过、集成测试真实识别断言通过；三平台 GUI 项见遗留清单）
- [ ] 三平台（Windows / macOS / Linux X11）手动验证：快捷键录音 → 识别 → 上屏全链路
- [◐] NFR-P-03：bench 实测 ≤10 秒语音全链 P95=81 ms ≤800 ms（本机参考值，mock 上屏；需基准机含真实目标应用复核）
- [ ] NFR-A-01 实测达标（普通话通用文本字准确率 ≥95%，需 ≥50 句基准测试集与基准机）
- [ ] NFR-P-06 空闲内存 ≤150 MB（不含模型，需真机测量）
- [ ] NFR-P-08 冷启动 ≤3 s 出现托盘、≤8 s 可首次录音（埋点已就位，需真机实测）
- [x] NFR-P-09 安装包 ≤120 MB（不含模型）：当前平台实测 5 MB
- [◐] 隐私核查：断网核心链路零网络依赖（代码与测试验证）；预热非录音丢弃路径测试断言；日志脱敏测试通过；真机断网复验待执行

### 发布前遗留清单（需人工 / 基准机）

1. NFR-P-01/02（预热首帧 ≤150 ms / 非预热 ≤500 ms）：埋点日志已输出，需真实麦克风 + 基准机。
2. 五大类代表应用上屏手动验证：VS Code（IDE）、终端、浏览器 AI 对话页、记事本、IM 输入框各一。
3. 真实全局快捷键与小窗入口全链路（含按住/切换双模式、Esc 取消三入口、焦点保持）。
4. 三平台托盘、悬浮球不抢焦点（Linux 记录各 WM 差异）、模型下载/切换/删除全流程、词典页操作、导出日志人工核查。
5. 已知限制（v0.1）：鼠标侧键暂不支持作为快捷键（E-HOTKEY-002，需平台级钩子，PRD 3.8.2 相关描述待产品确认修订）；`float_ball_position=cursor` 降级为底部居中；录音中修改快捷键会全量重注册、当轮 Esc 失效下轮恢复。

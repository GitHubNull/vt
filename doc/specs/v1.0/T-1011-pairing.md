## 1. 目标与范围

### 1.1 目标

实现桌面端配对服务：生成含一次性配对码的二维码、校验移动端配对请求、签发与保管长期令牌。

> 移动端边界：Android 客户端实现在 vt-mobile 仓库，本任务只实现桌面端并定义配对协议。

### 1.2 范围内

- PairingManager：一次性配对码（6 位数字 + 会话令牌，`rand` 生成），**有效期 2 分钟**，过期自动刷新；
- 二维码生成：`qrcode` 生成 → `image` 处理 → `base64` 输出前端展示；载荷 JSON：`{ v, addr, port, code, token_hint }`；
- 配对校验接口：移动端提交配对码 → 校验 → 签发长期令牌（32 字节）→ 存 OS 凭据管理器（每设备一条）；
- 配对成功双端确认：桌面端系统通知；
- 配对安全：仅局域网 / USB 通道；未配对连接弹确认框（拒绝则忽略并记录；同源连续 3 次被拒 10 分钟内不再提示）；
- 解除配对：吊销令牌。

### 1.3 范围外

- mDNS 广播（T-1012）、WebSocket 通道（T-1013）；
- 设备管理设置页（T-1015）；
- 手动连接码（T-1017）；
- Android 端实现（vt-mobile）。

- 新建：`src-tauri/src/services/device_hub.rs`（PairingManager 部分）、`src-tauri/src/commands/device.rs`；
- 依赖：qrcode、rand、image、base64（tech/02 已登记）；
- 复用：T-531 凭据层、T-003 配置。

## 4. 任务步骤

1. PairingManager：配对码生成 / 过期刷新 / 校验；
2. 二维码载荷与生成命令（前端展示）；
3. 长期令牌签发 / 存储 / 吊销；
4. 未配对连接确认流程（确认框事件 → 前端 → 用户决定）；
5. 同源拒绝计数与 10 分钟静默；
6. 单元测试：配对码生命周期、令牌签发与吊销、拒绝计数；
7. 联调：用测试脚本模拟移动端完成配对全流程。

## 5. 验收标准

- [ ] 二维码含配对码 / 地址 / 端口，配对码 2 分钟过期自动刷新；
- [ ] 正确配对码换取长期令牌；错误 / 过期码拒绝；
- [ ] 令牌存 OS 凭据管理器，配置文件与日志无明文；
- [ ] 配对成功桌面端弹系统通知；
- [ ] 未配对设备连接弹确认框；拒绝被记录；同源 3 次拒绝后 10 分钟静默；
- [ ] 解除配对后该设备令牌立即失效；
- [ ] 配对接口仅监听局域网 / 本机，不暴露公网。

## 1. 目标与范围

### 1.1 目标

实现"隐私与安全"设置分组：数据收集控制、敏感信息检测开关、一键清除本地数据、诊断模式。

### 1.2 范围内

- 隐私与安全页（`views/general/privacy` 或独立分组，按 PRD 导航）：
  - 匿名统计开关（默认关，NFR-PR-04）；
  - 敏感信息检测开关与命中行为配置；
  - AI 外发确认记录管理（查看已确认供应商、撤销确认）；
  - 一键清除本地数据（历史记录、统计、缓存；保留配置；二次确认）；
  - 诊断模式开关（日志级别提升，默认关）；
- 清除范围与行为以 PRD 3.8 节 F-SET-04 为准。

### 1.3 范围外

- 敏感信息检测引擎（T-1021）；
- 历史记录功能本身（T-1031）。

## 2. 需求依据

## 4. 任务步骤

1. 隐私与安全页布局与各设置项绑定；
2. 一键清除实现（范围枚举 + 二次确认 + 清除后提示）；
3. 外发确认记录管理与撤销；
4. 诊断模式联动日志级别；
5. Vitest：页面与清除流程；
6. 手动验证：清除后数据目录内容核查。

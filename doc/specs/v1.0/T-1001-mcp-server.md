## 1. 目标与范围

### 1.1 目标

实现 MCP 服务骨架：本机回环 HTTP 服务，默认关闭，令牌校验，为语音提问与访问控制提供基础。

### 1.2 范围内

- McpServer：MCP 协议（Streamable HTTP）服务端，仅绑定 `127.0.0.1`，端口可配；
- 默认关闭：设置中显式开启；开启时生成令牌（`rand`），存 OS 凭据管理器；
- 令牌校验中间件：每个请求校验，失败一律拒绝并记录（来源、时间；不区分错误类型）；
- 服务发现信息：设置页显示连接信息（地址 / 端口 / 令牌复制，掩码）；
- 能力注册框架：MCP tool / resource 的注册表（T-1002 / T-1003 注册具体能力）。

### 1.3 范围外

- 语音提问能力（T-1002）；
- 访问控制粒度与调用记录（T-1003）；
- MCP 设置页完整 UI（T-1004）。

## 5. 验收标准

- [ ] 服务默认关闭，开启后仅监听 127.0.0.1（`ss`/`netstat` 验证）；
- [ ] 无令牌 / 错误令牌请求一律拒绝，响应不区分失败原因，日志有记录；
- [ ] 令牌存 OS 凭据管理器，配置文件无明文；

- [ ] 关闭服务后端口释放；
- [ ] 日志不含令牌明文。

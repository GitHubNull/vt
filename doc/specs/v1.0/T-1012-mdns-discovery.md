## 1. 目标与范围

### 1.1 目标

实现桌面端 mDNS 服务广播：移动端可发现"附近的桌面端"，发起连接时桌面端弹确认框。

### 1.2 范围内

- MdnsBroadcaster：基于 `mdns-sd` 广播 `_vibetype._tcp.local.` 服务（含端口、设备名、版本）；
- 广播生命周期：移动麦克风总开关开启时广播，关闭 / 退出时停止；
- 设备名：默认主机名，可在设置中修改；
- 移动端发起连接的确认流程（与 T-1011 未配对确认衔接）；
- 局域网隔离环境检测与提示（引导 USB / 热点，PRD 异常处理）。

### 1.3 范围外

- WebSocket 通道（T-1013）；
- Android 端发现列表（vt-mobile）；
- USB 有线连接（T-1017 的 USB 部分属 v1.x 完善，本阶段协议预留）。

## 2. 需求依据

- F-MIC-02：局域网设备发现（PRD 3.14 节）；
- [tech/07](../../tech/07-mobile-link.md) 7.2.2。

## 3. 技术上下文

- 修改：DeviceHub（MdnsBroadcaster 部分）；
- 依赖：mdns-sd（tech/02 已登记）；
- 复用：T-1011 配对确认流程。

## 4. 任务步骤

1. mDNS 广播实现（服务类型、TXT 记录：端口 / 设备名 / 版本）；
2. 广播生命周期管理（跟随总开关）；
3. 设备名配置；
4. 发现连接确认流程联调；
5. 局域网隔离检测（广播失败 / 无接口）与引导提示；
6. 单元测试：广播参数、生命周期；
7. 手动验证：用 mDNS 浏览工具（如 `avahi-browse` / Bonjour 浏览器）确认广播可见。

## 5. 验收标准

- [ ] 总开关开启后局域网内可发现 `_vibetype._tcp.local.` 服务（mDNS 工具验证）；
- [ ] TXT 记录含端口 / 设备名 / 版本；
- [ ] 关闭总开关 / 退出应用后广播停止；
- [ ] 设备名修改后广播更新；
- [ ] 移动端（或模拟脚本）经 mDNS 发起连接时桌面端弹确认框；
- [ ] 局域网隔离环境给出 USB / 热点引导提示。

## 6. 测试要求

- `cargo test`：生命周期；
- 手动验证：mDNS 工具发现、隔离环境提示。

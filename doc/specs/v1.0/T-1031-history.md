## 1. 目标与范围

### 1.1 目标

实现识别历史记录：保存识别文本与元信息（时间、场景、是否 AI 处理），可查看、复制、删除、清空。

### 1.2 范围内

- 历史记录存储：仅识别 / 上屏**文本**与元信息，**不保存音频**（NFR-PR-02）；容量上限（按 PRD 3.1 节，超出滚动删除）；
- 历史记录页：列表（时间倒序）、搜索、复制、单条删除、清空；
- 隐私联动：一键清除（T-1022）包含历史；历史记录可在设置中整体关闭；
- 历史记录文件脱敏：不参与日志 / 备份的敏感外发（备份含历史时提示）。

### 1.3 范围外

- 语音回放（无音频，PRD 不提供）；
- 云端同步（不做）。

## 2. 需求依据

- F-INPUT-08：历史记录（PRD 3.1 节业务规则与验收标准）；
- NFR-PR-02：录音默认不保存；
- [tech/08](../../tech/08-data-and-security.md) 8.1。

## 3. 技术上下文

- 新建：HistoryService（数据目录 `history.jsonl` 或 SQLite，实施时定）、`src/views/` 历史页（导航位置按 PRD）；
- 复用：T-012 链路结果事件、T-002 外壳。

## 4. 任务步骤

1. 历史存储：追加写入、容量滚动、元信息（时间 / 场景 / 模板 / 降级标记）；
2. 链路接入：上屏成功后记录（含 AI 处理结果与原文关系标记）；
3. 历史页：列表 / 搜索 / 复制 / 删除 / 清空；
4. 设置项：历史记录开关（关闭后不记录）；
5. 与一键清除联动；
6. 单元测试：滚动、搜索、开关语义。

## 5. 验收标准

- [ ] PRD 3.1 节 F-INPUT-08 验收标准逐条通过；
- [ ] 历史只存文本与元信息，任何位置无音频文件（代码评审 + 文件系统核查）；
- [ ] 容量上限滚动正确；
- [ ] 搜索 / 复制 / 删除 / 清空可用；

- [ ] 一键清除后历史为空；
- [ ] 历史内容不写入日志。

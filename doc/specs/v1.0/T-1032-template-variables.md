## 1. 目标与范围

### 1.1 目标

实现模板上下文变量：模板中可引用 `{{selected_text}}`、`{{clipboard}}`、`{{scene}}` 等变量，渲染时从当前环境采集值。

### 1.2 范围内

- 变量集：PRD 3.5 节定义的上下文变量（选中文本、剪贴板、当前场景、时间等，以 PRD 为准）；
- 采集器：平台层获取选中文本（无障碍 API）/ 剪贴板 / 场景；权限缺失时变量为空并提示；
- 渲染引擎：模板渲染时替换变量（转义与注入安全）；
- 隐私约束：变量值（选中文本 / 剪贴板）不外泄到日志；随 AI 外发时走敏感信息检测（T-1021）；
- 模板编辑页变量插入辅助（变量列表 / 插入按钮）。

### 1.3 范围外

- 自定义变量（后续版本评估）；
- 模板引擎基础（T-533 已建）。

## 2. 需求依据

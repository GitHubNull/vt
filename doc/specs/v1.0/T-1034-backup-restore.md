## 1. 目标与范围

### 1.1 目标

实现配置与数据的备份导出 / 恢复导入：zip 打包，可选是否含密钥（加密导出），严格校验。

### 1.2 范围内

- 备份导出：选择内容范围（配置 / 词典 / 模板 / 布局 / 档案，不含历史与统计——或按 PRD 3.10 节范围）→ zip 打包（`zip` crate）→ plugin-dialog 选保存位置；
- 密钥选项：默认不含密钥；用户显式选择"含密钥"时导出 OS 凭据的加密副本（用户设置导出密码），界面明确提示风险；
- 恢复导入：文件校验（格式 / 版本 / zip bomb 防护：条目数与总大小上限）→ 预览内容 → 确认 → 恢复（恢复前自动备份当前配置）；
- 备份文件脱敏核查：未选含密钥时备份中无任何密钥 / 令牌（NFR-S-02）；
- 敏感信息提示：导出内容含敏感信息样式时提示（T-1021 检测）。

### 1.3 范围外

- 自动备份调度（后续版本评估）；
- 控制键布局单独导入导出（T-1016 已含，备份包统一包含）。

## 4. 任务步骤

1. 备份打包：范围枚举 → zip（含清单 manifest 与版本）；
2. 密钥加密导出路径（密码派生加密，界面风险提示）；
3. 恢复：校验 → 预览 → 自动备份当前 → 恢复 → 重启生效提示；
4. zip bomb 防护与异常文件测试集；
5. 备份脱敏核查自动化（导出后扫描断言无密钥模式）；
6. 单元测试：打包 / 校验 / 恢复回滚。

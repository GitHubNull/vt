## 1. 目标与范围

### 1.1 目标

实现 MCP 设置页：服务开关、连接信息（地址 / 端口 / 令牌）、能力授权开关、调用记录查看。

### 1.2 范围内

- MCP 页（`views/ai/mcp`，替换 v0.5 占位页）：服务开关、状态显示（运行中 / 已停止、端口）；
- 连接信息：地址、端口、令牌（掩码显示、复制按钮、重新生成）；
- 能力授权：逐项开关（默认关）；
- 调用记录：列表（时间 / 客户端 / 能力 / 结果）、清空按钮；
- 对照原型截图 `PixPin_2026-10-09_21-34-32.png`。

### 1.3 范围外

- MCP 服务端实现（T-1001 ~ T-1003）。

## 1. 目标与范围

### 1.1 目标

实现"移动麦克风"设置页：总开关、添加设备（配对面板）、已配对设备管理、安全设置。

### 1.2 范围内

- "通用 › 录音环境"的"移动麦克风"卡片替换为真实功能 + "管理设备"入口；托盘菜单"连接手机"入口；
- 设备管理页：总开关（默认开）、"添加设备"面板（二维码 + 配对码 + 手动连接码标签页，对照 PRD 3.14）；
- 已配对设备列表：设备名、连接方式、状态、信号与延迟、重命名、解除配对（确认对话框）；
- 安全设置：仅允许已配对设备（默认开）、新设备连接须确认（默认开）、传输加密（默认开不可关，置灰）；
- 低电量标记（<15% 设备列表标注）；
- 设备状态实时更新（`device:changed`）。

### 1.3 范围外

- 配对 / 通道服务端（T-1011 ~ T-1013）；
- 控制键布局编辑器（T-1016 的桌面端部分含布局管理，移动端编辑器在 vt-mobile）。

## 2. 需求依据

- NFR-S-08：安全设置默认值；

## 4. 任务步骤

1. 设备管理页布局（配对面板 + 设备列表 + 安全设置）；
2. 配对面板：二维码展示（base64 图）、配对码倒计时刷新、手动连接码标签页；
3. 设备列表：状态实时更新、重命名（持久化）、解除配对（确认 + 令牌吊销）；
4. 安全设置三项绑定（加密项置灰不可关）；
5. 托盘"连接手机"入口（打开管理页 / 配对面板）；
6. 低电量标记；
7. Vitest：页面与 store；联调：模拟设备连接全流程。

## 1. 目标与范围

### 1.1 目标

实现深色主题：设置项（浅色 / 深色 / 跟随系统），全部窗口（设置 / 小窗 / 悬浮球）正确切换。

### 1.2 范围内

- 深色主题定义：PrimeVue 深色预设定制 + CSS 变量深色集（`data-theme` 切换，T-002 已预留机制）；
- 设置项：浅色 / 深色 / 跟随系统（监听系统主题变化）；
- 全窗口覆盖：设置主窗口、语音小窗、悬浮球（含动效颜色）；
- 视觉对照 PRD 第 4 章深色规范（如 PRD 有）；对比度满足可访问性（NFR 可访问性一节）。

### 1.3 范围外

- 英文界面（T-1037）；
- 主题自定义（不做）。

## 2. 需求依据

- F-SET-01：主题（PRD 3.8 节）；
- PRD 第 4 章视觉规范；
- [tech/03](../../tech/03-frontend.md) 3.3 / 3.7。

## 3. 技术上下文

- 修改：`src/styles/`（深色变量集）、主题切换 store、三个窗口入口；
- 复用：T-002 主题机制。

## 4. 任务步骤

1. 深色 CSS 变量集与 PrimeVue 深色预设接入；
2. 主题设置项与持久化，跟随系统的系统事件监听；
3. 三窗口统一切换（事件广播）；
4. 悬浮球 / 小窗动效颜色深色适配；
5. 对比度自查（关键文本与背景）；
6. 三平台手动验证：切换与跟随系统。

## 5. 验收标准

- [ ] 主题设置三选项生效，重启保持；
- [ ] 跟随系统时系统主题切换应用即时跟随；
- [ ] 全部窗口深色下无"漏白"组件（逐页截图核查）；
- [ ] 关键文本对比度满足 WCAG AA（4.5:1）；
- [ ] 三平台手动验证通过。

## 6. 测试要求

- Vitest：主题 store；
- 手动验证：三平台切换与截图核查。

## 7. 完成定义（DoD）

- 验收标准全部勾选；

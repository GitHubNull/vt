# T-1021 敏感信息检测完整版

| 项目 | 内容 |
| --- | --- |
| 任务编号 | T-1021 |
| 所属阶段 | v1.0 正式版 |
| 优先级 | P0 |
| 覆盖需求 | NFR-S-03（敏感信息检测全量规则）、F-SET-04（部分） |
| 前置依赖 | v0.5 T-535（基础版） |

## 1. 目标与范围

### 1.1 目标

把 v0.5 的敏感信息检测基础版扩展为完整规则库，覆盖 PRD 定义的全部敏感信息类别。

### 1.2 范围内

- 完整规则库：云服务 / 大模型密钥格式、私钥、密码赋值、手机号、身份证、银行卡、邮箱、内网地址（NFR-S-03 全量）；
- 规则引擎：正则 + 校验位（如银行卡 Luhn）降低误报；
- 触发点全覆盖：AI 外发前（已有）、备份导出时提示；
- 命中处理：自动打码 + 用户确认提示（可查看命中类别，不回显完整命中内容）；
- 规则库版本化：可随应用版本更新扩充。

### 1.3 范围外

- 隐私与安全设置分组 UI（T-1022）；
- AI 外发闸门本身（T-535 已建）。

## 2. 需求依据

- NFR-S-03：敏感信息检测覆盖全部类别，本地完成；
- 产品原则 5（隐私优先）；
- [tech/08](../../tech/08-data-and-security.md) 8.5。

## 3. 技术上下文

- 修改：敏感信息检测器（T-535 基础版扩展）；
- 复用：T-535 闸门、T-1034 备份导出（并行开发时预留接口）。

## 4. 任务步骤

1. 规则库数据化（类别 → 规则集，含校验位逻辑）；
2. 检测引擎：多规则扫描、命中分类、打码；
3. 测试样本集：每类别 ≥20 条正样本 + 误报样本集；
4. 备份导出触发点接入；
5. 命中提示 UI（类别级，不回显完整内容）；
6. 单元测试：每类别检出率与误报率统计。

## 5. 验收标准

- [ ] NFR-S-03 全部类别有规则覆盖且测试样本检出；
- [ ] 误报率控制在可接受水平（误报样本集统计，随 PR 附数据）；
- [ ] AI 外发与备份导出两个触发点均生效；
- [ ] 命中提示不回显完整敏感内容；
- [ ] 检测全程本地完成（无网络调用，代码评审确认）；
- [ ] 命中内容不写入日志。

## 6. 测试要求

- `cargo test`：规则库全量；
- 样本集检出 / 误报报告随 PR 附上。

## 7. 完成定义（DoD）

- 验收标准全部勾选；
- 提交信息：`feat: 敏感信息检测完整规则库`。

## 1. 目标与范围

### 1.1 目标

实现"我的"模块的个人档案页：用户可维护影响识别与改写的个人信息（以 PRD 3.10 节定义的字段为准）。

### 1.2 范围内

- 个人档案页（`views/me/profile`）：PRD 3.10 节定义的字段（如称呼、职业 / 角色、常用技术栈、发音习惯补充等，以 PRD 为准）；
- 档案数据的消费点接通：常用技术栈联动词库默认启用集（T-521）、AI 模板可用档案变量（如 PRD 定义）；
- 持久化与隐私：档案存本机配置，随一键清除可选项（PRD 规则）。

### 1.3 范围外

- 备份与恢复（T-1034）；
- 账号体系（产品无账号，PRD 明确本地优先）。

## 2. 需求依据

- F-ME-01：个人档案（PRD 3.10 节字段与验收标准）；

## 1. 目标与范围

### 1.1 目标

完成英文界面翻译与语言切换：界面语言设置（简体中文 / English），切换即时生效。

### 1.2 范围内

- `src/i18n/en-US.ts`：全部界面文案的英文翻译（与 zh-CN 键完全对齐）；
- 语言切换即时生效（不重启）；识别语言与界面语言独立（PRD 国际化一节）；
- 翻译质量：技术术语准确（与 PRD 术语表一致）；
- 文案完整性检查：脚本校验 zh-CN 与 en-US 键集合一致（CI 可跑）；
- 布局适配：英文长文案导致的布局溢出自查（按钮、标签、表格）。

### 1.3 范围外

- 繁體中文（v1.x）；
- FAQ 等动态内容的双语（FAQ 内容 v1.0 可仅中文，注明）。

## 2. 需求依据

- F-SET-01：界面语言（PRD 3.8 节）；
- PRD 国际化一节：首发简体中文 / English，切换即时生效，识别语言与界面语言独立；
- [tech/03](../../tech/03-frontend.md) 3.2（i18n 约定）。

## 3. 技术上下文

- 新建：`src/i18n/en-US.ts`、键对齐校验脚本；
- 复用：T-002 i18n 机制、T-013 语言设置项。

## 4. 任务步骤

1. 全量翻译 en-US（对照 zh-CN 键）；
2. 语言切换即时生效机制（响应式 locale）；
3. 键对齐校验脚本（`pnpm run i18n:check`）；
4. 英文界面全页面走查（布局溢出修正）；
5. Vitest：语言切换。

## 5. 验收标准

- [ ] 界面语言切换为 English 后全部页面即时生效（无残留中文界面文案，FAQ 内容除外）；
- [ ] 切换不需重启；
- [ ] 识别语言不受界面语言影响（独立设置验证）；
- [ ] 键对齐校验脚本通过；
- [ ] 英文布局无溢出 / 截断（逐页截图核查）；
- [ ] 术语翻译与 PRD 术语表一致。

## 6. 测试要求

- Vitest：切换；
- 手动验证：英文界面全页面走查。

## 7. 完成定义（DoD）

- 验收标准全部勾选；

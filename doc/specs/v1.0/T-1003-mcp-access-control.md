## 1. 目标与范围

### 1.1 目标

实现 MCP 能力的逐项访问控制与调用记录：按能力授权、调用留痕、记录可查看与清空。

### 1.2 范围内

- 能力注册表：`ask_user`、专有名词查询、专有名词建议（后两者本任务实现，调 DictService）；
- 访问控制：按能力逐项授权开关（默认全部关闭，用户逐项开启）；
- 调用记录：时间、客户端标识、能力、参数摘要（脱敏）、结果状态；持久化 7 天自动清理；
- 记录查看：设置页列表 + 清空按钮；
- 未授权能力调用：拒绝并记录。

### 1.3 范围外

- MCP 设置页整体布局（T-1004 整合）；
- 提问能力本身（T-1002）。

- [tech/06](../../tech/06-ai-and-mcp.md) 6.2.2。

## 3. 技术上下文

- 修改：McpServer（能力注册表 + 授权检查 + 记录器）；
- 新建：记录存储（数据目录，7 天滚动）；
- 复用：DictService（T-522）。

## 4. 任务步骤

1. 能力注册表与授权配置模型（能力 → 开关）；
2. 专有名词查询 / 建议两个能力实现（DictService 对接）；
3. 授权检查中间件（未授权拒绝 + 记录）；
4. 调用记录器：结构化记录、7 天滚动清理；
5. 记录查看命令与清空命令；
6. 单元测试：授权矩阵、记录滚动、脱敏。

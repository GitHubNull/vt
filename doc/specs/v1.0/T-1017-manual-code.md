# T-1017 手动连接码兜底

| 项目 | 内容 |
| --- | --- |
| 任务编号 | T-1017 |
| 所属阶段 | v1.0 正式版 |
| 优先级 | P2 |
| 覆盖需求 | F-MIC-03（手动连接码部分） |
| 前置依赖 | T-1011 |

## 1. 目标与范围

### 1.1 目标

实现手动连接码配对兜底：扫码与 mDNS 均不可用时，移动端手动输入桌面端展示的 6 位一次性连接码完成配对。

### 1.2 范围内

- 配对面板"手动连接码"标签页：6 位一次性码展示（与扫码共用 PairingManager 的码生命周期）；
- 移动端手动输入码的校验路径（复用 T-1011 校验接口，码来源标记为手动）；
- 地址手动输入配合：移动端需手动填桌面端 IP / 端口（协议支持，桌面端展示当前局域网地址与端口）。

### 1.3 范围外

- USB 有线连接（F-MIC-03 的 USB 部分，v1.x 完善）；
- Android 端手动输入 UI（vt-mobile）。

## 2. 需求依据

- F-MIC-03：手动连接码（PRD 3.14 节：6 位一次性连接码，兜底场景）；
- NFR-S-08：一次性限时配对码；
- [tech/07](../../tech/07-mobile-link.md) 7.2.2。

## 3. 技术上下文

- 修改：T-1015 配对面板（标签页）、PairingManager（码来源标记）；
- 复用：T-1011 全部配对机制。

## 4. 任务步骤

1. 配对面板增加手动连接码标签页（码 + 局域网地址 + 端口展示）；
2. 校验接口支持码来源标记（扫码 / 手动）；
3. 单元测试：手动码路径；
4. 联调：模拟手动输入流程。

## 5. 验收标准

- [ ] 手动连接码标签页展示 6 位码、地址、端口，码 2 分钟过期刷新；
- [ ] 移动端手动输入正确码完成配对（签发长期令牌）；
- [ ] 错误 / 过期码拒绝；
- [ ] 与扫码共用同一安全规则（一次性、限时）。

## 6. 测试要求

- `cargo test`：手动码路径；
- 手动验证：模拟手动配对流程。

## 7. 完成定义（DoD）

- 验收标准全部勾选；

# T-1018 移动麦克风双端联调与异常路径

| 项目 | 内容 |
| --- | --- |
| 任务编号 | T-1018 |
| 所属阶段 | v1.0 正式版 |
| 优先级 | P1 |
| 覆盖需求 | F-MIC-04 / F-MIC-06 / F-MIC-07 的异常与边界（PRD 3.14 节） |
| 前置依赖 | T-1014、T-1015、T-1016 + vt-mobile Android 端就绪 |

## 1. 目标与范围

### 1.1 目标

与 vt-mobile Android 客户端进行真实双端联调，覆盖 PRD 3.14 节全部异常与边界场景，收口移动麦克风能力。

### 1.2 范围内

- 真实 Android 设备联调：配对（扫码 / mDNS / 手动码）、录音、控制键、状态同步；
- 异常路径全覆盖：
  - 录音中断连：已采集部分照常识别上屏，双端提示，移动端自动重连；
  - 移动端来电 / 被打断：同断连处理，通话结束自动重连；
  - 电量 <15%：移动端提示 + 桌面端列表低电量标记；
  - 桌面端休眠 / 锁屏：连接保持，唤醒自动恢复（锁屏录音权限按设置，默认允许）；
  - 局域网隔离：引导 USB / 热点；
  - 未配对设备连接：确认框、拒绝记录、3 次静默；
- 多设备场景：一台桌面端配多台设备、同时只允许一台录音（先按先得）；一台设备切多个桌面端；
- 性能实测：音频往返延迟 ≤200 ms（局域网良好环境）。

### 1.3 范围外

- Android 端缺陷修复（vt-mobile 仓库处理，本任务只记录联调问题）；
- 虚拟麦克风（v1.x）。

## 2. 需求依据

- PRD 3.14 节"异常与边界"全部条目；
- PRD 兼容性指标：延迟 ≤200 ms、断连音频不丢失；
- [tech/07](../../tech/07-mobile-link.md) 全章。

## 3. 技术上下文

- 依赖 vt-mobile 仓库 Android 端达到可联调状态（其仓库任务）；
- 本任务主要是测试与缺陷修复（桌面端侧）。

## 4. 任务步骤

1. 准备联调环境（Android 设备 + 局域网）；
2. 按 PRD 3.14 异常清单逐项执行并记录结果；
3. 多设备场景验证；
4. 延迟实测（多组样本取 P95）；
5. 发现的桌面端缺陷修复；移动端缺陷提交 vt-mobile issue；
6. 输出联调报告（场景 × 结果矩阵）。

## 5. 验收标准

- [ ] PRD 3.14 节异常与边界全部场景实测通过或有修复记录；
- [ ] 多设备配对与录音互斥正确；
- [ ] 音频往返延迟 P95 ≤200 ms（实测数据）；
- [ ] 断连已采集音频不丢失；
- [ ] 联调报告随 PR 附上；
- [ ] 移动端遗留问题全部在 vt-mobile 仓库有对应 issue。

## 6. 测试要求

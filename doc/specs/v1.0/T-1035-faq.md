## 1. 目标与范围

### 1.1 目标

实现"常见问题"页：问题分类浏览与搜索，内容覆盖三平台常见使用问题。

### 1.2 范围内

- FAQ 页（`views/faq/`）：分类导航 + 问题列表 + 搜索（标题与内容关键词）；
- FAQ 内容：数据文件驱动（JSON / Markdown 资源），覆盖 PRD 3.11 节分类（权限、识别、口令、AI、设备、平台差异如 Linux AppIndicator 等）；
- 内容维护机制：FAQ 数据随应用版本更新，条目含相关设置页 deep link（点击跳转对应设置）。

### 1.3 范围外

- 在线 FAQ 更新（后续版本评估，v1.0 内容随版本内置）。

## 2. 需求依据

- F-FAQ-01：问题分类与搜索（PRD 3.11 节）；
- [tech/03](../../tech/03-frontend.md) 3.6。

## 3. 技术上下文

- 新建：`src/views/faq/`、FAQ 数据资源文件；

| 项目 | 内容 |

## 1. 目标与范围

### 1.1 目标

实现技术词库：按技术栈组织的术语包（Java、前端、Python、Go、Rust、云原生、数据库、AI 大模型等），启用后识别结果中的术语自动纠正为标准写法。

### 1.2 范围内

- 词库数据格式：术语条目（标准写法、读音别名 / 常见误识别形、所属技术栈）；
- 内置术语包：PRD 3.3 节列出的技术栈，每栈一份初始词表（内容按 PRD 附录 / 示例整理）；
- 词库 Stage 或替换词典扩展：术语纠正接入后处理管线（与替换词典的优先级规则按 PRD）；
- 词库管理页：技术栈启用 / 停用、条目浏览与搜索；
- 与 ASR 的协同：读音别名作为识别后纠正映射（不改模型）。

### 1.3 范围外

- 专有名词（F-DICT-02，T-522）；
- 项目术语导入（F-CODE-07，v1.0）；
- 团队共享词库（v1.x）。

## 2. 需求依据

- F-CODE-06：技术词库（PRD 3.3 节业务规则与验收标准）；
- NFR-A-02：编程术语准确率 ≥90%（启用词库）；
- [tech/05](../../tech/05-core-pipeline.md) 5.1。

## 3. 技术上下文

- 新建：词库数据文件（`src-tauri` 资源 / 配置目录 `dict/tech/`）、DictService 扩展、`src/views/coding/` 词库管理页；
- 复用：T-011 管线与词典持久化、T-002 外壳。

## 4. 任务步骤

1. 定义词库数据格式与加载机制（多文件按技术栈组织）；
2. 整理内置术语包初版（覆盖 PRD 列出的技术栈，每栈核心术语）；
3. 术语纠正 Stage 接入管线，与替换词典的优先级按 PRD 规则；
4. 词库管理页：技术栈开关、条目浏览 / 搜索；
5. 准确率测试集：≥100 条含编程术语的语句，启用词库后术语准确率 ≥90%（NFR-A-02）；
6. 单元测试：纠正规则、优先级、启用切换即时生效。

## 5. 验收标准

- [ ] PRD 3.3 节 F-CODE-06 验收标准逐条通过；
- [ ] 各技术栈词库可独立启停，即时生效；
- [ ] "Redis"不再变成"瑞迪斯"类纠正生效（PRD 示例逐条）；
- [ ] 术语准确率测试集 ≥90%（NFR-A-02）；
- [ ] 词库全部停用时原文直出；
- [ ] 词库文件损坏时跳过该文件并提示，不崩溃（NFR-S-07）。

## 6. 测试要求

- `cargo test`：纠正规则、加载、优先级；
- 准确率测试集报告随 PR 附上。

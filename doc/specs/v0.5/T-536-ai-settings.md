## 1. 目标与范围

### 1.1 目标

实现 AI 模块设置页：供应商列表与配置、模型列表管理、连通性测试、模板页入口。

### 1.2 范围内

- 供应商页（`views/ai/providers`）：预置供应商列表（**渲染前去重**，原型问题修正清单）、展开配置（base_url、API Key 掩码输入、默认模型）、启用开关、自定义供应商添加；
- 模型管理：拉取模型按钮、手动添加 / 删除、连通性测试按钮与结果展示（延迟 / 错误编号）；
- API Key 输入：掩码显示、保存后只显示"已设置"、更换需二次确认；
- 模板页入口与 MCP 页占位（MCP 标注 v1.0 提供）。

### 1.3 范围外

- 模板管理页本身（T-533）；
- MCP 服务（v1.0 T-1001 ~ T-1004）。

## 1. 目标与范围

### 1.1 目标

实现替换词典、专有名词、技术词库条目的统一导入导出，含严格的格式校验。

### 1.2 范围内

- 导出：选择词典类型 → 导出为 JSON 文件（plugin-dialog 选路径），格式带版本号；
- 导入：文件选择 → 格式校验（JSON Schema + 版本兼容 + 条目数量 / 长度上限）→ 冲突处理（跳过 / 覆盖 / 合并，UI 让用户选）→ 导入报告（成功 / 跳过条数）；
- 校验失败：拒绝导入并给出原因，不崩溃、不执行文件内容（NFR-S-07）；
- 设置页入口：词典各页面加导入 / 导出按钮。

### 1.3 范围外

- 整体备份与恢复（F-ME-02，v1.0 T-1034）；
- 团队共享（v1.x）。

## 2. 需求依据

- F-DICT-03：导入导出（PRD 3.4 节）；
- NFR-S-07：导入文件须格式校验，异常文件不得导致崩溃或执行；
- [tech/08](../../tech/08-data-and-security.md) 8.6 导入文件校验。

## 3. 技术上下文

- 新建：DictService 导入导出部分、导入向导 UI 组件；
- 复用：T-011/T-521/T-522 词典服务、plugin-dialog。

## 4. 任务步骤

1. 定义导入导出文件格式（JSON Schema，含版本字段）；
2. 导出实现（三类词典分别导出）；
3. 导入实现：Schema 校验 → 上限检查 → 冲突策略 → 写入 → 报告；
4. 异常文件测试集：畸形 JSON、超大文件、字段缺失、版本不兼容、嵌套攻击性内容——全部安全拒绝；
5. UI：导入向导（选文件 → 校验结果 → 冲突策略 → 报告）；
6. 单元测试：Schema、冲突策略、异常文件。

## 1. 目标与范围

### 1.1 目标

实现场景规则：每个场景对应一套标点 / 空格 / 口令行为配置，识别到场景后自动应用；提供设置页让用户调整各场景规则与自定义应用归类。

### 1.2 范围内

- 场景规则模型：场景 → { 标点策略、中英间距策略、口令启用集、终端保护开关 }，默认值以 PRD 3.2.1 节为准；
- 规则应用：PipelineContext 携带场景规则，后处理 Stage 读取执行；
- 设置页（`views/coding/scenes`）：各场景规则编辑、应用归类自定义（应用 → 场景）；
- 场景锁定：用户可锁定当前场景（不被自动切换），锁定状态可见。

### 1.3 范围外

- 口令 Stage 实现（T-512 ~ T-516）；
- 场景识别本身（T-501）。

## 2. 需求依据

- F-CODE-01：场景规则（PRD 3.2.1 节业务规则与验收标准）；
- 产品原则 3：场景行为可配置、可关闭；
- [tech/05](../../tech/05-core-pipeline.md) 5.1 管线场景 Stage。

## 3. 技术上下文

- 新建：`src/views/coding/ScenesView.vue`、SceneService 规则部分扩展；
- 复用：T-501 场景识别、T-003 ConfigStore、T-002 设置外壳。

## 4. 任务步骤

1. 定义场景规则数据结构与默认值（PRD 3.2.1），持久化到配置；
2. 规则注入管线：录音开始时快照当前场景规则进 PipelineContext；
3. 场景锁定：命令 + 状态事件，锁定期间自动识别结果不应用；
4. 设置页：场景列表 → 规则编辑表单；应用归类管理（添加 / 移除自定义归类）；
5. 单元测试：规则快照、锁定语义、归类合并；
6. 手动验证：切换应用场景规则生效（用标点策略差异验证）。

## 5. 验收标准

- [ ] PRD 3.2.1 节 F-CODE-01 验收标准逐条通过；

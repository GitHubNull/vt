# T-515 终端安全保护

| 项目 | 内容 |
| --- | --- |
| 任务编号 | T-515 |
| 所属阶段 | v0.5 Beta |
| 优先级 | P0 |
| 覆盖需求 | F-CODE-05（终端安全保护）、NFR-S-05 |
| 前置依赖 | T-501、T-514 |

## 1. 目标与范围

### 1.1 目标

实现终端场景的安全保护：终端中只上屏不执行，危险命令醒目提醒，杜绝"识别错误直接回车"。这是产品原则 4（安全第一）的核心落地。

### 1.2 范围内

- 终端场景约束注册：向 CommandEngine 场景钩子注册终端规则——**禁止回车类按键口令自动执行**（回车口令在终端场景降级为文本提示 / 忽略，行为以 PRD 3.2.5 节为准）；
- 危险命令检测：上屏文本匹配危险模式（`rm -rf`、`sudo`、管道到 shell 等，PRD 词表）时醒目标记（悬浮球 / 小窗警告样式 + 提示文案）；
- 绕过防护核查：词典替换、AI 模板、口令任何路径均不得绕过终端约束（统一在按键执行出口强制检查）；
- 用户显式确认机制：PRD 允许的用户主动执行路径（如有）按 PRD 实现；
- 专项测试：终端安全测试清单（PRD 验收标准）全量执行。

### 1.3 范围外

- 场景识别本身（T-501）；
- 移动端终端布局约束（v1.0 T-1016，复用本任务规则）。

## 2. 需求依据

- F-CODE-05：终端安全保护（PRD 3.2.5 节）；
- NFR-S-05：终端场景默认禁止自动回车，任何口令 / 词典规则不得绕过；
- 产品原则 4：宁可漏转不可错转；
- v0.5 发布标准：终端安全保护通过专项测试。

## 3. 技术上下文

- 修改：CommandEngine 场景钩子实现、InjectService 按键出口强制检查；
- 复用：T-501 场景识别、T-514 按键口令、T-008/T-009 警告 UI 扩展。

## 4. 任务步骤

1. 在按键执行出口实现强制检查层：场景 = 终端且按键 ∈ 回车类 → 按 PRD 规则降级（该层不可被配置关闭）；
2. CommandEngine 注册终端场景约束；
3. 危险命令模式库与检测（上屏前扫描）；
4. 警告 UI：悬浮球 / 小窗的危险命令醒目样式（对照 PRD 第 4 章）；
5. 绕过测试矩阵：词典替换构造回车、AI 模板输出含执行意图、口令组合——逐一验证均被拦截；
6. 专项测试清单执行并记录结果。

## 5. 验收标准

- [ ] PRD 3.2.5 节 F-CODE-05 验收标准逐条通过；
- [ ] 终端场景下"回车"口令不产生 Enter 按键事件（三平台实测）；
- [ ] 危险命令上屏前有醒目警告（UI 截图验证）；
- [ ] 绕过矩阵全部拦截：词典 / 口令 / AI 输出任何路径均无法让终端自动执行（NFR-S-05）；
- [ ] 非终端场景按键口令行为不受影响；
- [ ] 强制检查层无配置项可关闭（代码评审确认）；
- [ ] 三平台终端（Windows Terminal / iTerm2 / GNOME Terminal）手动验证通过。

## 6. 测试要求

- `cargo test`：检查层、危险模式库；
- 专项测试：绕过矩阵全量；
- 三平台手动验证。

## 7. 完成定义（DoD）

- 验收标准全部勾选；
- 专项测试结果记录随 PR 附上；
- 提交信息：`feat: 终端安全保护（禁自动回车与危险命令提醒）`。

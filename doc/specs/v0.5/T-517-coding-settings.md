## 1. 目标与范围

### 1.1 目标

实现"编程"模块设置页：口令总开关与各口令分组开关、场景规则入口、终端安全保护状态展示。

### 1.2 范围内

- 编程设置页（`views/coding/`）：口令分组开关（命名风格 / 符号 / 按键）、中英混排开关、场景规则入口（链到 T-502 页面）、终端安全保护说明与状态；
- 各开关绑定对应 Stage / 引擎配置，即时生效；
- 口令词表只读预览（让用户知道有哪些口令可用）。

### 1.3 范围外

- 场景规则编辑页（T-502）；
- 技术词库管理页（T-521）。

## 2. 需求依据

- PRD 3.2 节：编程模块的交互与设置项；
- 产品原则 3：任何自动改写可关闭；
- [tech/03](../../tech/03-frontend.md) 3.6。

## 3. 技术上下文

- 新建：`src/views/coding/` 页面；
- 复用：T-002 外壳、T-003 useConfigStore、T-511 ~ T-516 各 Stage 开关。

## 4. 任务步骤

1. 编程设置页布局（对照 PRD 第 4 章）；
2. 各开关绑定配置并联动对应 Stage 启停；
3. 口令词表只读预览（分组展示触发词与效果示例）；
4. 终端安全保护状态卡片（始终开启的说明）；
5. Vitest：页面渲染与开关绑定。

## 5. 验收标准

- [ ] 各口令分组可独立开关，关闭后对应口令不再触发（链路实测）；
- [ ] 中英混排开关生效；
- [ ] 场景规则入口可达 T-502 页面；
- [ ] 终端安全保护显示为始终开启，无关闭入口；
- [ ] 设置重启后保持；
- [ ] 页面无硬编码文案。

## 6. 测试要求

- Vitest：页面与 store；
- 手动验证：开关切换 → 链路行为变化。

## 7. 完成定义（DoD）

- 验收标准全部勾选；
- 提交信息：`feat: 编程设置页`。

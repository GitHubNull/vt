# T-514 按键口令

| 项目 | 内容 |

| 任务编号 | T-514 |
| 所属阶段 | v0.5 Beta |
| 优先级 | P1 |

## 1. 目标与范围

### 1.1 目标

实现按键口令：说"回车""换行""Tab""撤销"等触发对应按键事件（区别于符号口令的文本字符输出）。

### 1.2 范围内

- 按键词表：PRD 3.2.4 节全部按键（回车、换行、Tab、Esc、方向键、删除、组合键如"撤销""保存"等）；
- 组合键的 OS 修饰键映射（Ctrl / Cmd 按平台自动映射）；
- 按键事件经 InjectService `press_key` 注入当前焦点应用；
- 与文本上屏的顺序保证：同一录音会话内文本与按键按口令顺序执行；
- 终端场景的按键约束接口（T-515 实现具体规则，本任务预留场景检查钩子）。

### 1.3 范围外

- 终端安全保护规则（T-515）；
- 移动端控制键（v1.0 T-1016，复用本任务的按键注入能力）。

## 2. 需求依据

- F-CODE-04：按键口令（PRD 3.2.4 节示例与验收标准）；
- NFR-A-06：按键口令误触发率 ≤0.5%；
- NFR-S-05：终端场景默认禁止自动回车（钩子预留）；
- [tech/05](../../tech/05-core-pipeline.md) 5.1。

## 3. 技术上下文

- 修改：CommandEngine 词表（`KeyPress(key, modifiers)` 分支）；
- 复用：T-511 的 InjectService `press_key` 扩展。

## 4. 任务步骤

1. 按键词表数据化（触发词 → 键码 + 修饰键，平台映射表）；
2. 组合键解析（"撤销" → Ctrl/Cmd+Z 等，PRD 词表为准）；
3. 文本与按键混合序列的顺序执行；
4. 场景检查钩子：执行按键前查询场景规则（T-515 注册终端约束）；
5. PRD 全部按键示例转为测试用例；
6. 误触发测试集：≥100 条含按键词的普通语句，误触发率 ≤0.5%（NFR-A-06）。

## 5. 验收标准

- [ ] PRD 3.2.4 节全部按键口令示例在目标应用行为正确；
- [ ] 组合键在 macOS 用 Cmd、其他平台用 Ctrl（自动映射）；
- [ ] 文本 + 按键混合口令按顺序执行；
- [ ] 误触发测试集误触发率 ≤0.5%（NFR-A-06）；
- [ ] 场景检查钩子可被注册并生效（用假规则验证）；
- [ ] 三平台手动验证通过。

## 6. 测试要求

- `cargo test`：词表、映射、顺序；
- 误触发测试集报告；
- 三平台手动验证：编辑器 / 终端中按键行为。

## 7. 完成定义（DoD）

- 验收标准全部勾选；
- 提交信息：`feat: 按键口令`。

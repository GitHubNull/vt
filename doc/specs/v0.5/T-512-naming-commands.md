## 1. 目标与范围

### 1.1 目标

实现命名风格口令：说"驼峰 user name"得到 `userName`，支持 PRD 3.2.2 节定义的全部命名风格。

### 1.2 范围内

- 命名风格词表与转换器：驼峰（小驼峰 / 大驼峰）、蛇形、常量、短横线等 PRD 列出的风格；
- 多词 payload 处理：口令后的词序列按风格拼接（大小写、分隔符规则）；
- payload 边界判定：口令作用范围（到下一个口令 / 标点 / 停顿标记为止），规则以 PRD 为准；
- 与技术词库联动：payload 中的术语按词库标准写法输出（接口对接 T-521）。

### 1.3 范围外

- 符号口令（T-513）、按键口令（T-514）；
- 自定义命名风格（v1.x）。

## 2. 需求依据

- F-CODE-02：命名风格口令（PRD 3.2.2 节示例与验收标准）；
- NFR-A-04：命名风格口令正确率 ≥95%；
- [tech/05](../../tech/05-core-pipeline.md) 5.1。

## 3. 技术上下文

- 修改：CommandEngine 词表与转换器（T-511 框架内扩展）；
- 复用：T-511 AST `Transform(style, payload)`。

## 4. 任务步骤

1. 实现各命名风格转换函数（纯函数，全量单测）；
2. 词表登记：风格触发词（"驼峰""大驼峰""蛇形""常量"等，以 PRD 为准）；
3. payload 边界判定逻辑实现；
4. PRD 3.2.2 节全部示例转为测试用例；
5. 准确率测试集：≥100 条命名口令样本，统计正确率（NFR-A-04 门槛 95%）。

## 5. 验收标准

- [ ] PRD 3.2.2 节全部示例转换正确（"驼峰 user name" → `userName` 等）；
- [ ] 每种 PRD 列出的命名风格均有测试覆盖；
- [ ] 准确率测试集正确率 ≥95%（NFR-A-04）；
- [ ] 非口令语境（如"驼峰是一种动物"讨论文本）不误触发；
- [ ] 口令 Stage 关闭时原文直出。

## 6. 测试要求

- `cargo test`：转换函数、边界判定、PRD 示例；
- 准确率测试集报告（随 PR 附上）。

## 7. 完成定义（DoD）

- 验收标准全部勾选；

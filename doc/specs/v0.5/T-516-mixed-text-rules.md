## 1. 目标与范围

### 1.1 目标

实现中英混排规范化 Stage：中英文之间的空格、大小写、标点按 PRD 规则自动处理，解决"中英混说一塌糊涂"的痛点。

### 1.2 范围内

- 混排 Stage（管线中位置：替换词典之后、口令 Stage 之前 / 之后的顺序以 PRD 3.2.6 节规则为准）；
- 规则集：中英文间空格、英文大小写保留（术语词库联动）、中文语境标点转中文标点 / 代码语境保留半角等（以 PRD 3.2.6 节为准）；
- 场景差异：IDE / 文档场景的混排规则差异（场景规则 T-502）；
- Stage 独立开关。

### 1.3 范围外

- 技术词库本身（T-521）；
- ASR 引擎侧的识别改进（属模型能力）。

## 2. 需求依据

- F-CODE-08：中英混排规范（PRD 3.2.6 节业务规则与验收标准）；
- NFR-A-03：中英混说整句正确率 ≥80%（本 Stage 与词库共同支撑）；
- [tech/05](../../tech/05-core-pipeline.md) 5.1。

## 3. 技术上下文

- 新建：混排 Stage（`services/post_process.rs` 内新增 Stage 实现）；
- 复用：T-011 管线、T-502 场景规则、T-521 词库接口（并行开发时先以接口 mock）。

## 4. 任务步骤

1. 实现混排规则引擎（纯函数规则集，全量单测）；
2. Stage 接入管线，顺序按 PRD 规则确定；
3. 场景规则联动；
4. PRD 3.2.6 节全部示例转为测试用例；
5. 中英混说测试集：≥100 句，整句正确率统计（与词库联调后 ≥80%，NFR-A-03）。

## 5. 验收标准

- [ ] PRD 3.2.6 节全部示例输出正确；
- [ ] 中英文间空格、大小写、标点规则在 IDE / 文档场景下分别正确；
- [ ] 中英混说测试集整句正确率 ≥80%（NFR-A-03，与 T-521 联调后测）；
- [ ] Stage 关闭时原文直出；
- [ ] 规则不破坏代码片段内容（代码语境测试集验证）。

## 6. 测试要求

- `cargo test`：规则集、PRD 示例；
- 测试集报告随 PR 附上。

## 7. 完成定义（DoD）

- 验收标准全部勾选；
- 提交信息：`feat: 中英混排规范`。

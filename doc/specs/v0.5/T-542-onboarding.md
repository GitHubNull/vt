## 1. 目标与范围

### 1.1 目标

实现首次启动引导流程：权限授予、模型下载、快捷键教学，让新用户顺利完成首次语音输入。

### 1.2 范围内

- 引导流程（首启触发，完成后标记不再显示，可在关于页重新打开）：
  1. 欢迎与产品简介；
  2. 权限引导：麦克风、辅助功能（macOS）等，逐项检测与跳转授权；
  3. 模型下载：推荐模型一键下载（进度显示）；
  4. 快捷键教学：按住 / 切换模式说明 + 现场试录一次；
  5. 完成页：进入小窗 / 设置；
- 权限检测命令：麦克风 / 辅助功能状态查询；
- 跳过路径：每一步可跳过（跳过后对应功能降级的提示）。

### 1.3 范围外

- 更新后的新功能引导（后续版本评估）；
- 移动麦克风引导（v1.0）。

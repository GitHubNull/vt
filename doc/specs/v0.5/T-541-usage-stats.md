# T-541 使用统计

| 项目 | 内容 |
| --- | --- |
| 任务编号 | T-541 |
| 所属阶段 | v0.5 Beta |
| 优先级 | P1 |

| 前置依赖 | v0.1 T-003 |

## 1. 目标与范围

### 1.1 目标

实现本地使用统计：录音次数、时长、上屏字数、口令 / 模板使用次数等指标，统计页可视化展示。全部数据仅存本机。

### 1.2 范围内

- 统计采集：链路埋点（录音完成、上屏成功、降级、口令触发、模板使用等），仅计数与时长，**不采集任何文本内容**；
- 本地存储：统计数据存数据目录（按天聚合）；
- 统计页（`views/stats/`）：PRD 3.9 节定义的指标与图表（趋势、分布）；
- 匿名统计上报开关：默认关闭（NFR-PR-04），开启逻辑 v0.5 只做设置项占位（上报通道未建，注明）。

### 1.3 范围外

- 任何数据上报通道（默认零收集，上报需另行立项）；
- 历史记录（F-INPUT-08，v1.0）。

## 2. 需求依据

- F-STAT-01：使用统计（PRD 3.9 节指标定义与验收标准）；
- NFR-PR-04：默认零数据收集，匿名统计须用户主动开启；
- 产品原则 5（隐私优先）。

## 3. 技术上下文

- 新建：`src-tauri/src/services/stats.rs`、`src/views/stats/`；
- 复用：链路各服务事件（T-012）、T-003 存储、T-002 外壳。

## 4. 任务步骤

1. StatsService：订阅链路事件，按天聚合计数（原子写入）；
2. 统计页：指标卡片与图表（轻量图表实现或 Canvas 自绘，控制依赖体积）；
3. 埋点接入：录音 / 上屏 / 降级 / 口令 / 模板事件；
4. 匿名统计开关占位（默认关，注明上报通道未建）；
5. 单元测试：聚合逻辑、跨天边界；
6. 隐私核查：统计数据 Schema 评审确认无文本内容。

## 5. 验收标准

- [ ] PRD 3.9 节 F-STAT-01 验收标准逐条通过；
- [ ] 统计页指标与实际使用一致（录音 N 次后数据正确）；
- [ ] 统计数据不含任何识别文本 / 用户内容（Schema 与代码评审确认）；
- [ ] 默认无任何网络上报（抓包 / 代码评审验证）；
- [ ] 重启后统计数据保持。

## 6. 测试要求

- `cargo test`：聚合与持久化；
- 手动验证：使用后统计页数据正确。

## 7. 完成定义（DoD）

- 验收标准全部勾选；
- 提交信息：`feat: 本地使用统计`。

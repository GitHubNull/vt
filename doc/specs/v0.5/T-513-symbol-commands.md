| 项目 | 内容 |

## 1. 目标与范围

### 1.1 目标

实现符号口令：说"左括号""箭头""冒号"等直接输出对应符号，覆盖 PRD 3.2.3 节的符号词表。

### 1.2 范围内

- 符号词表：PRD 3.2.3 节全部符号（括号类、箭头、运算符、标点等），含中英文触发词；
- 符号输出为文本字符（非按键事件），与命名风格口令可组合（"驼峰 user 左括号 name 右括号"）；
- 场景差异：文档沟通场景下符号口令默认行为（是否触发）按场景规则（T-502）执行；
- 误转换控制：符号词在普通语句中的歧义处理（PRD 规则）。

### 1.3 范围外

- 按键口令（T-514，按键事件而非文本字符）；
- 自定义符号（v1.x）。

## 2. 需求依据

- F-CODE-03：符号口令（PRD 3.2.3 节示例与验收标准）；
- NFR-A-05：符号口令误转换率 ≤1%；
- [tech/05](../../tech/05-core-pipeline.md) 5.1。

## 3. 技术上下文

- 修改：CommandEngine 词表（`Symbol(sym)` 分支）；
- 复用：T-511 解析器、T-502 场景规则。

## 4. 任务步骤

1. 符号词表数据化（触发词 → 符号字符，多触发词映射同一符号）；
2. 歧义规则实现（PRD 3.2.3：何种语境触发 / 不触发）；
3. PRD 全部符号示例转为测试用例；
4. 误转换测试集：≥100 条含符号词的普通语句，统计误转换率（NFR-A-05 门槛 ≤1%）；
5. 场景规则联动验证：文档场景下符号口令按配置行为执行。

## 5. 验收标准

- [ ] PRD 3.2.3 节全部符号口令示例输出正确；
- [ ] 误转换测试集误转换率 ≤1%（NFR-A-05）；
- [ ] 符号口令与命名风格口令组合输入正确；
- [ ] 场景规则关闭符号口令时原文直出；
- [ ] 三平台手动验证（符号字符在各目标应用显示正确）。

## 6. 测试要求

- `cargo test`：词表、歧义规则、PRD 示例；
- 误转换测试集报告（随 PR 附上）。

## 7. 完成定义（DoD）

- 验收标准全部勾选；
- 提交信息：`feat: 符号口令`。

## 1. 目标与范围

### 1.1 目标

实现快捷键冲突的系统性检测：注册时检测系统占用、应用内快捷键（录音键 / 模板键）互斥检测，并给出冲突提示与修改引导。

### 1.2 范围内

- 系统级冲突：注册失败时的归因（被其他应用占用）与提示；
- 应用内冲突：多个可配置快捷键（录音键、模板键）之间的重复检测（保存配置时校验）；
- 冲突提示 UI：设置页快捷键录入时即时反馈冲突；
- 常见系统快捷键预警：录入与 OS 常用组合（如 Ctrl+C）冲突时警告（不禁止，警告即可）。

### 1.3 范围外

- 快捷键功能本身（T-004 / T-534）。

## 2. 需求依据

- F-SYS-03：快捷键冲突检测（PRD 3.13 节）；
- [tech/04](../../tech/04-backend.md) 4.4 HotkeyService。

## 3. 技术上下文

- 修改：HotkeyService（冲突检测）、T-013 快捷键录入组件；
- 复用：T-003 配置。

## 4. 任务步骤

1. 应用内冲突校验：配置保存前检查全部快捷键集合无重复；
2. 系统占用检测：注册失败归因与提示文案；
3. OS 常用组合预警表（三平台各自清单）；
4. 设置页录入组件接入即时校验反馈；
5. 单元测试：冲突校验逻辑；
6. 手动验证：制造冲突（占用 / 重复 / 系统组合）三种场景。

## 1. 目标与范围

### 1.1 目标

支持团队级别的词库与模板共享：以文件 / Git 仓库方式分发与订阅，保持"本地优先"（不引入账号体系与云端服务）。

### 1.2 范围内

- 共享包格式：词库 + 模板的打包格式（复用导入导出 Schema 扩展，含版本与来源信息）；
- 订阅机制：从 Git 仓库 / 文件 URL 拉取共享包，手动 / 启动时更新检查；
- 冲突与优先级：团队共享条目与个人条目的优先级规则（立项时 PRD 定义）；
- 来源可信与校验：共享包格式校验（NFR-S-07），来源展示；
- 设置页：共享源管理（添加 / 移除 / 更新）。

### 1.3 范围外

- 任何账号 / 登录 / 云端同步服务（违背本地优先，不做）；
- 共享包的在线托管市场（不做）。

## 2. 需求依据

- PRD 6.1 v1.x：团队共享词库与模板（以文件 / 仓库方式）；
- 产品原则 1（本地优先）：共享仅作为分发方式，运行时不依赖网络；
- NFR-S-07：导入校验。

## 3. 技术上下文

- 复用：T-523 导入导出、T-1034 zip 与校验、T-521 词库、T-533 模板；
- 共享包格式设计立项时评审并更新 tech/08。

## 4. 任务步骤（方向性）

1. 立项细化 PRD（优先级规则、更新策略、验收标准）；
2. 共享包格式与订阅协议设计；
3. 订阅与更新实现；
4. 冲突合并与优先级；
5. 设置页与验证。

## 5. 验收标准（方向性，立项时细化）

- [ ] 可从 Git 仓库 URL 订阅共享词库 / 模板包；
- [ ] 更新检查与拉取可用，失败有明确提示；
- [ ] 共享条目与个人条目优先级符合 PRD 规则；
- [ ] 异常共享包安全拒绝（NFR-S-07）；
- [ ] 断网时已订阅内容照常可用（本地优先）。

## 6. 测试要求

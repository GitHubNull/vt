# T-2002 USB 有线连接完善

| 项目 | 内容 |
| --- | --- |
| 任务编号 | T-2002 |
| 所属阶段 | v1.x |
| 优先级 | P2 |
| 覆盖需求 | F-MIC-03（USB 有线连接部分） |
| 前置依赖 | v1.0 T-1013（WebSocket 通道） |

> **v1.x SPEC 说明**：方向性规格，立项执行前先细化 PRD 再修订本 SPEC（见 v1.x 路线图说明）。

## 1. 目标与范围

### 1.1 目标

实现移动设备的 USB 有线连接：数据线连接自动识别，覆盖无网络 / 网络隔离环境与极低延迟场景。

### 1.2 范围内

- USB 通道建立：Android ADB 端口转发 / USB 网络共享（tethering）等方案的选型与实现（桌面端侧）；
- 连接复用现有协议：USB 通道建立后复用 WebSocket 协议与配对体系（tech/07 协议不变）；
- 自动识别：数据线连接后桌面端自动发现并提示；
- 连接方式标记：设备列表显示"USB 连接"。

### 1.3 范围外

- Android 端 USB 模式实现（vt-mobile）；
- iOS 任何内容（已决策暂缓）。

## 2. 需求依据

- F-MIC-03：手动连接码 / 有线连接（PRD 3.14 节：USB 有线连接，数据线连接自动识别；无网络 / 极低延迟场景）；
- NFR-S-08：仅局域网 / USB 通道；
- [tech/07](../../tech/07-mobile-link.md) 7.2.2。

## 3. 技术上下文

- 复用：T-1011 配对、T-1013 通道（协议不变，仅传输层替换）；
- USB 方案选型立项时评审并更新 tech/07。

## 4. 任务步骤（方向性）

1. 立项细化 PRD（USB 连接的业务规则与验收标准）；
2. USB 传输方案选型与原型验证；
3. 传输层接入 DeviceHub（协议复用）；
4. 自动识别与设备列表标记；
5. 无网络环境实测。

## 5. 验收标准（方向性，立项时细化）

- [ ] 数据线连接后桌面端自动识别移动设备；
- [ ] USB 通道内配对 / 录音 / 控制键全部可用（协议复用验证）；
- [ ] 完全断网（无局域网）环境下 USB 链路可用；
- [ ] 设备列表正确显示 USB 连接方式；
- [ ] USB 连接延迟优于或等于局域网（实测记录）。

## 6. 测试要求

- 真实 Android 设备 USB 连接手动验证；
- 无网络环境场景验证。

## 7. 完成定义（DoD）

- PRD 细化后的验收标准全部通过；
- tech/07 更新 USB 传输设计；
- 提交信息：`feat: USB 有线连接`。

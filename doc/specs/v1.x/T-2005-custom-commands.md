## 1. 目标与范围

### 1.1 目标

让用户可以自定义编程口令：自定义触发词 → 文本片段 / 符号 / 按键 / 组合动作，扩展内置口令词表。

### 1.2 范围内

- 自定义口令数据模型：触发词、动作类型（文本 / 符号 / 按键 / 组合）、参数、所属分组、启用开关；
- CommandEngine 扩展：自定义词表与内置词表合并（冲突规则：自定义优先或报错，立项时 PRD 定）；
- 管理 UI：自定义口令的增删改查（编程设置页扩展）；
- 导入导出：自定义口令随词典导入导出 / 备份体系（格式校验 NFR-S-07）；
- 误触发控制：自定义口令同样受场景规则与误触发防护约束。

### 1.3 范围外

- 口令脚本化（如正则 / 编程表达式，超出口令定位，不做或另行立项）；
- 口令市场 / 共享（T-2003 团队共享可覆盖）。

## 2. 需求依据

- PRD 6.1 v1.x：自定义编程口令；
- F-CODE-02/03/04 的扩展动机；
- NFR-A-05/06：自定义口令不得恶化误转换 / 误触发指标。

## 3. 技术上下文

- 复用：T-511 CommandEngine（词表数据驱动设计已预留）、T-517 设置页、T-523 导入导出。

## 4. 任务步骤（方向性）

1. 立项细化 PRD（冲突规则、动作类型边界、验收标准）；
2. 自定义口令模型与存储；
3. 引擎合并与冲突处理；
4. 管理 UI 与导入导出；
5. 误触发回归测试（自定义口令加入后 NFR-A-05/06 仍达标）。

## 5. 验收标准（方向性，立项时细化）

- [ ] 用户可创建自定义口令（文本 / 符号 / 按键 / 组合动作）并生效；
- [ ] 自定义与内置口令冲突时行为符合 PRD 规则；
- [ ] 自定义口令可导入导出，异常文件安全拒绝；
- [ ] 加入自定义口令后 NFR-A-05/06 指标仍达标；
- [ ] 自定义口令受场景规则约束（终端安全不可绕过，NFR-S-05）。

## 6. 测试要求

- `cargo test`：合并与冲突；
- 误触发测试集回归。

## 7. 完成定义（DoD）

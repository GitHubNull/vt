# T-2006 更多界面语言

| 项目 | 内容 |
| --- | --- |
| 任务编号 | T-2006 |
| 所属阶段 | v1.x |
| 优先级 | P2 |
| 覆盖需求 | PRD 6.1 v1.x / 国际化一节：繁體中文等更多界面语言 |
| 前置依赖 | v1.0 T-1037（i18n 完整化） |

> **v1.x SPEC 说明**：方向性规格，立项执行前先细化 PRD 再修订本 SPEC。

## 1. 目标与范围

### 1.1 目标

在 i18n 体系上新增界面语言（首批：繁體中文；后续语言按社区反馈排期）。

### 1.2 范围内

- `src/i18n/zh-TW.ts`：繁體中文全量翻译（与 zh-CN 键对齐）；
- 语言设置项纳入新语言；
- 术语对照：两岸技术术语差异处理（如"内存 / 記憶體"）；
- 布局适配自查（繁体字符宽度与简体接近，风险低，仍需走查）；
- 键对齐校验脚本扩展覆盖新语言。

### 1.3 范围外

- 识别语言扩展（属 ASR 模型能力，不在本任务）；
- 其他语言（立项时按社区反馈追加）。

## 2. 需求依据

- PRD 国际化一节：v1.x 增繁體中文；语言切换即时生效；识别语言与界面语言独立。

## 3. 技术上下文

- 复用：T-1037 的 i18n 机制与校验脚本。

## 4. 任务步骤

1. 繁體中文全量翻译；
2. 语言设置项与即时切换；
3. 键对齐校验扩展；
4. 全页面走查。

## 5. 验收标准（方向性，立项时细化）

- [ ] 繁體中文界面全量可用，切换即时生效；
- [ ] 键对齐校验通过；
- [ ] 术语翻译符合繁体技术语境习惯；
- [ ] 布局无溢出 / 截断。

## 6. 测试要求

- Vitest：切换；
- 手动走查。

## 7. 完成定义（DoD）

- PRD 细化后的验收标准全部通过；
- 提交信息：`feat: 繁體中文界面`。

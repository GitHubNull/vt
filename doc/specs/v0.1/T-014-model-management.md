## 1. 目标与范围

### 1.1 目标

实现模型管理设置页：模型列表展示、下载（含进度）、切换、删除，让用户可以管理本地识别模型。

### 1.2 范围内

- 模型管理页（`views/general/models` 或独立路由，按 PRD 导航）：内置推荐模型清单（档位、大小、说明）、已下载状态、当前激活模型；
- 下载：进度条（消费 T-006 下载进度事件）、取消下载、失败重试；
- 切换：激活模型切换（调 T-006 命令），切换后识别即时生效；
- 删除：确认对话框（plugin-dialog），删除文件并回退到可用模型；
- 档位说明：各档位预期耗时与准确率提示（对照 NFR-P-03/04 与 NFR-A-01）。

### 1.3 范围外

- 自定义模型导入（PRD 未要求）；
- 首次启动的模型下载引导（v0.5 T-542）。

## 2. 需求依据

- F-SET-06：模型管理（PRD 3.8 节）；
- NFR-P-09：安装包不含模型，首启下载；
- [tech/04](../../tech/04-backend.md) 4.4 AsrService；
- [tech/03](../../tech/03-frontend.md) 3.3（PrimeVue 组件）。

## 3. 技术上下文

- 新建：`src/views/general/ModelsView.vue`（或按路由约定）、`src/stores/asr.ts`；
- 复用：T-006 的模型命令与进度事件；T-002 外壳。

## 4. 任务步骤

1. 实现模型列表页：卡片 / 表格展示档位、大小、状态（未下载 / 下载中 / 已下载 / 激活中）；
2. 下载交互：进度条、取消、失败重试（错误编号提示）；
3. 激活切换：确认后调用切换命令，切换中禁用重复操作；
4. 删除：确认对话框，删除后若删除的是激活模型则回退到首个可用模型并提示；
5. 档位说明文案（入 i18n）；
6. Vitest：store 状态流转（下载中 → 已下载 → 激活）。

## 5. 验收标准

- [ ] PRD 3.8 节 F-SET-06 验收标准逐条通过；
- [ ] 模型下载进度实时显示，可取消，失败可重试；
- [ ] 切换模型后识别结果来自新模型（日志 / 行为验证）；
- [ ] 删除激活模型时正确回退并提示；
- [ ] 无可用模型时录音入口给出明确引导（下载模型），不崩溃；
- [ ] 断网时下载给出网络错误提示（错误编号），已下载模型识别不受影响。

- 手动验证：下载 → 切换 → 识别 → 删除全流程；断网场景。

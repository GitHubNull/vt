## 1. 目标与范围

### 1.1 目标

实现"关于"页：版本信息展示与更新检查、日志导出、法律信息（许可证与免责声明）。

### 1.2 范围内

- 版本信息：产品名、版本号、构建信息；检查更新按钮（NFR-PR-06：只发送版本号 / OS / 架构；v0.1 更新服务器未就绪时实现客户端逻辑 + 可配置地址，无更新时正常提示）；
- 更新包签名校验机制接入（Tauri Updater 公钥配置，NFR-S-06；v0.1 验证"签名校验失败拒绝安装"路径）；
- 导出日志（F-ABOUT-02）：打包最近日志（含 OS 版本、产品版本、模型信息、最近 1000 行），经脱敏层处理，用 plugin-dialog 选保存位置；
- 法律信息（F-ABOUT-03）：LICENSE 与 DISCLAIMER.md 内容展示、第三方组件声明入口；
- 打开外部链接一律用 plugin-opener。

### 1.3 范围外

- 真实更新服务器部署（发布流程事项）；
- 自动更新后台检查调度（v0.1 手动触发即可）。

## 4. 任务步骤

1. 关于页布局：版本卡片、更新检查区、日志导出、法律信息区（对照截图）；
2. UpdateService：版本检查请求（仅版本号 / OS / 架构）、Tauri Updater 接入与公钥配置、签名校验失败拒绝路径；
3. LogService 导出：收集最近日志 → 脱敏过滤复核 → 附系统信息头 → zip / 文本保存（plugin-dialog 选路径）；
4. 法律信息：渲染 LICENSE / DISCLAIMER 文本，第三方组件声明列表页（占位结构，内容随依赖完善）；
5. 外部链接（官网 / 仓库）用 plugin-opener；
6. 文案入 i18n；
7. 测试：导出日志文件人工核查无敏感内容（构造含密钥样式字符串的日志，确认被脱敏）。

# T-013 通用设置页

| 项目 | 内容 |
| --- | --- |
| 任务编号 | T-013 |
| 所属阶段 | v0.1 MVP |
| 优先级 | P0 |
| 覆盖需求 | F-SET-01（界面语言 / 主题）、F-SET-02（文本输出选项）、F-SET-03（录音环境）、F-SET-05（系统与数据） |
| 前置依赖 | T-002、T-003 |

## 1. 目标与范围

### 1.1 目标

实现"通用"模块的全部设置页，让用户可以配置界面、输入与录音、文本输出、录音环境、系统与数据选项。

### 1.2 范围内

- 界面（F-SET-01）：界面语言（v0.1 仅简体中文，选项预留）、主题（浅色，深色置灰标注 v1.0）；
- 输入与录音（F-SET-01 关联 / F-INPUT-01/02 配置面）：快捷键修改（键位录制输入框）、按住 / 切换模式选择；
- 文本输出（F-SET-02）：PRD 3.8 节定义的输出选项（如末尾标点、换行偏好等，以 PRD 为准）；
- 录音环境（F-SET-03）：麦克风设备选择（调 T-005 枚举命令）、常驻预热开关、"移动麦克风"卡片占位（标注 v1.0 提供，不实现功能）；
- 系统与数据（F-SET-05）：开机自启、数据目录位置展示（`@tauri-apps/plugin-opener` 打开）、诊断模式开关（日志级别）；
- 所有设置项读写走 useConfigStore（T-003），即时生效（快捷键等走对应服务热更新）。

### 1.3 范围外

- 模型管理（T-014）、隐私与安全分组（v1.0）、移动麦克风管理（v1.0）；
- 深色主题与英文翻译的实际内容（v1.0）。

## 2. 需求依据

- PRD 3.8 节：通用设置的用户故事、业务规则与验收标准；
- F-SET-01/02/03/05 功能清单；
- [tech/03](../../tech/03-frontend.md) 3.4 / 3.6；
- 参考截图：`doc/img/语音输入法界面原型截图参考/PixPin_2026-10-09_21-35-49.png`。

## 3. 技术上下文

- 新建：`src/views/general/` 各分组页面；
- 复用：T-002 外壳与路由、T-003 useConfigStore、T-004 快捷键重注册、T-005 设备枚举命令；
- 快捷键录制输入框：捕获按键组合 → 校验 → 写配置（冲突错误由 T-004 服务返回）。

## 4. 任务步骤

1. 实现五个分组页面（界面 / 输入与录音 / 文本输出 / 录音环境 / 系统与数据），布局对照原型截图与 PRD 第 4 章；
2. 快捷键录制组件：聚焦后捕获按键，显示键位名称，保存触发 T-004 热注册，失败显示错误编号提示；
3. 麦克风选择：下拉列表来自设备枚举命令，切换即时生效；
4. 各开关 / 选项绑定 useConfigStore，失败回滚并提示；
5. 数据目录"打开所在位置"用 plugin-opener；
6. 移动麦克风卡片：标题 + "v1.0 提供"占位说明（不实现管理功能）；
7. 文案全部入 `src/i18n/`；
8. Vitest：各页面渲染与 store 交互。

## 5. 验收标准

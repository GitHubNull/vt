# T-015 系统托盘菜单

| 项目 | 内容 |
| --- | --- |
| 任务编号 | T-015 |
| 所属阶段 | v0.1 MVP |
| 优先级 | P0 |
| 覆盖需求 | F-SYS-01（托盘菜单） |
| 前置依赖 | T-001 |

## 1. 目标与范围

### 1.1 目标

实现系统托盘：应用常驻后台的入口，提供核心操作菜单（打开小窗、打开设置、退出等）。

### 1.2 范围内

- Tauri TrayIcon：托盘图标（正常 / 录音中两种状态）、菜单；
- 菜单项（以 PRD 3.13 节为准）：打开语音输入小窗、打开设置、（v1.0 预留"连接手机"占位不显示）、退出；
- 录音状态联动：录音中托盘图标切换为录音态；
- 关闭主窗口不退出应用（最小化到托盘）；
- 左键点击行为按 PRD（默认唤起小窗）。

### 1.3 范围外

- "连接手机"菜单项（v1.0）；
- 开机自启的实现（T-013 设置项 + 平台自启注册，本任务只做托盘）。

## 2. 需求依据

- F-SYS-01：托盘菜单（PRD 3.13 节）；
- NFR-P-08：冷启动 ≤3 s 出现托盘；
- [tech/09](../../tech/09-cross-platform.md) 9.2.5（Linux AppIndicator 注意事项）。

## 3. 技术上下文

- 修改：`src-tauri/src/main.rs`（托盘注册）、窗口关闭行为；
- 新建：托盘图标资源（`src-tauri/icons/`，含录音态）；
- 复用：T-009 的 `show_mini_window`、T-002 设置窗口创建逻辑、录音状态事件。

## 4. 任务步骤

1. 准备托盘图标（正常 / 录音中两态，三平台尺寸适配）；
2. 注册 TrayIcon 与菜单：打开小窗 / 打开设置 / 退出；
3. 订阅录音状态事件切换图标；
4. 主窗口关闭事件拦截：隐藏窗口而非退出；
5. 左键点击唤起小窗；
6. 退出菜单：优雅关停（服务 shutdown、配置落盘）；
7. 冷启动埋点：进程启动到托盘可见的耗时日志（NFR-P-08）；
8. Linux 验证 AppIndicator 环境（无 AppIndicator 时在 FAQ 预备条目，本任务记录行为）。

## 5. 验收标准

- [ ] 应用启动后 ≤3 s 托盘图标可见（NFR-P-08 埋点实测）；
- [ ] 菜单各项功能正确：打开小窗、打开设置、退出；
- [ ] 录音中托盘图标切换为录音态，结束恢复；
- [ ] 关闭设置窗口应用不退出，托盘仍在；
- [ ] 退出后进程完全退出，无残留；
- [ ] 三平台手动验证通过（Linux 记录桌面环境差异）。

## 6. 测试要求

- 手动验证为主（托盘无法单测）：三平台菜单、图标状态、退出；
- 冷启动耗时日志核查。

## 7. 完成定义（DoD）

- 验收标准全部勾选；
- 提交信息：`feat: 系统托盘菜单与常驻后台`。

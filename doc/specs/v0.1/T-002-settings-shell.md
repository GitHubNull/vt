## 1. 目标与范围

### 1.1 目标

实现设置主窗口的三栏式外壳：一级导航侧边栏、二级导航 / 分组、内容区，路由与 PRD 第 2 章导航体系一一对应，为后续所有设置页提供容器。

### 1.2 范围内

- 三栏布局（侧边栏 / 分组栏 / 内容区），符合 PRD 第 4 章布局规范；
- vue-router 路由表：覆盖 v0.1 需要的页面（通用设置各分组、模型管理、关于）与 v0.5+ 占位路由（词典、编程、AI、统计、我的、常见问题——渲染"敬请期待"占位组件）；
- 路由懒加载；PrimeVue 主题接入（浅色，CSS 变量 + `data-theme` 机制预留深色）；
- i18n 骨架（`src/i18n/` zh-CN 文案文件，语言切换机制预留）；
- 侧边栏导航项以 PRD v1.3 为准，**不含"音视频转录"**，不重复渲染（原型问题修正清单）。

### 1.3 范围外

- 任何设置页的具体表单内容（T-013 / T-014 / T-016 负责）；
- 深色主题与英文文案的实际翻译（v1.0 T-1036 / T-1037）；
- 悬浮球与小窗（T-008 / T-009）。

## 2. 需求依据

- PRD 第 2 章（导航体系）、第 4 章（窗口与布局、视觉规范）；
- F-SET-01：界面语言 / 主题设置入口存在；
- NFR-P-10：设置窗口打开 ≤500 ms；
- [tech/03 前端架构](../../tech/03-frontend.md)：3.2 目录、3.3 PrimeVue 约定、3.6 路由与布局、3.7 样式；
- AGENTS.md 第 4 节：对照原型截图与"原型问题修正清单"。

## 3. 技术上下文

- 新建：`src/App.vue`、`src/router.ts`、`src/views/` 各模块目录与占位组件、`src/i18n/`、`src/styles/`；
- 复用：T-001 的 PrimeVue / Pinia 接入；
- 参考截图：`doc/img/语音输入法界面原型截图参考/PixPin_2026-10-09_21-35-49.png`（通用设置页布局）。

## 4. 任务步骤

1. 实现 `App.vue` 三栏布局（侧边栏固定宽度、分组栏可折叠、内容区滚动），样式变量入 `styles/`；
2. 定义路由表：路径与 PRD 第 2 章导航对应（`/general/interface`、`/general/input`、`/general/output`、`/general/recording`、`/general/system`、`/general/models`、`/about`，及占位 `/dict/*`、`/coding/*`、`/ai/*`、`/stats`、`/me/*`、`/faq`）；
3. 全部路由懒加载；占位组件统一为 `ComingSoon.vue`；
4. 接入 PrimeVue 主题（浅色预设 + CSS 变量），`data-theme` 切换机制预留；
5. 建立 `src/i18n/zh-CN.ts`，本任务所有可见文案入该文件；
6. 侧边栏导航渲染自路由元信息（单一数据源，杜绝重复渲染）；
7. 对照原型截图核查布局与修正清单。

## 5. 验收标准

- [ ] 设置窗口三栏布局与 PRD 第 4 章一致，对照原型截图无明显偏差；
- [ ] 侧边栏导航项与 PRD v1.3 导航体系一致，**无"音视频转录"项**；
- [ ] 每个导航项可进入对应路由，v0.5+ 模块显示占位页；
- [ ] 侧边栏无重复渲染（DOM 中每个导航项唯一）；
- [ ] 设置窗口从托盘打开到可交互 ≤500 ms（NFR-P-10，手动计时验证）；
- [ ] 所有可见文案来自 `src/i18n/`，组件内无硬编码文案；
- [ ] `pnpm typecheck` / `pnpm lint` 通过。

## 6. 测试要求

- Vitest：路由表与导航元信息一致性快照测试；
- 手动验证：当前平台窗口缩放、导航切换、占位页展示。

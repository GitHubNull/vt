# T-009 语音输入小窗

| 项目 | 内容 |

| 任务编号 | T-009 |

## 1. 目标与范围

### 1.1 目标

实现语音输入小窗：一个可常驻的轻量窗口，中央麦克风按钮即可开始 / 结束录音，是快捷键之外的第二触发入口。

### 1.2 范围内

- mini 窗口前端页（`src/mini/`）：居中大麦克风按钮（按住说话 / 切换模式跟随设置）、录音状态与音量反馈、取消按钮；
- 窗口生命周期：托盘菜单 / 命令唤起，可常驻；关闭按钮最小化到托盘（不退出应用）；
- 与快捷键共用同一录音状态机（单会话互斥）；
- 唤起命令：`show_mini_window`（托盘菜单 T-015 消费）。

### 1.3 范围外

- 托盘菜单本身（T-015）；
- 模板选择（v0.5+）、场景显示（v0.5+）；
- 移动端遥控（v1.0）。

## 2. 需求依据

- F-INPUT-06：语音输入小窗，一个麦克风按钮即可开始；
- PRD 第 4 章：小窗布局与交互；
- [tech/03](../../tech/03-frontend.md) 3.1 mini 窗口；
- 参考截图：`doc/img/语音输入法界面原型截图参考/PixPin_2026-10-09_21-38-03.png`。

## 3. 技术上下文

- 新建：`src/mini/` 页面、后端 `show_mini_window` 命令；
- 复用：T-004 / T-005 的录音控制通道与状态事件；T-003 配置（模式跟随）。

## 4. 任务步骤

1. 实现 mini 页面：按 PRD 第 4 章与参考截图实现布局（麦克风按钮、状态文案、音量反馈、取消按钮）；
2. 按钮交互：按住模式 = 按下开始 / 松开结束；切换模式 = 点击翻转（读取配置）；
3. 接入 `recording:state` / `recording:level` / `recording:result` 事件驱动 UI；
4. 后端命令：`show_mini_window`（已存在则聚焦显示）；
5. 关闭按钮行为：隐藏窗口而非退出；
6. 与快捷键触发的互斥验证：录音中小窗按钮显示进行中状态，不可重复触发。

## 5. 验收标准

- [ ] 小窗通过命令唤起，布局与 PRD 第 4 章 / 参考截图一致；
- [ ] 按住 / 切换两种模式按钮行为正确（跟随设置）；
- [ ] 录音中小窗显示状态与音量反馈；
- [ ] 快捷键已开始录音时，小窗按钮显示进行中、不可重复触发；
- [ ] 关闭小窗不退出应用，托盘可再次唤起；
- [ ] 三平台手动验证通过。

## 6. 测试要求

- Vitest：按钮交互逻辑（模式分支）；
- 三平台手动验证：唤起、录音、关闭、再唤起。

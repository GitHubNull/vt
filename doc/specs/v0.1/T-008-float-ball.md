# T-008 录音悬浮球

| 项目 | 内容 |

| 所属阶段 | v0.1 MVP |

## 1. 目标与范围

### 1.1 目标

实现录音期间的悬浮反馈球：音量动效、时长、模式显示、取消入口，全程不抢输入焦点。

### 1.2 范围内

- float 窗口前端页（`src/float/`）：音量波形 / 呼吸动效、录音时长、当前模式（按住 / 切换）、取消区域；
- 窗口生命周期：录音开始创建、结束销毁；位置记忆（上次拖动位置存配置）；
- 不抢焦点：`focusable: false` + 平台差异处理（tech/09 9.2.4）；无可聚焦控件；
- 事件接入：`recording:state` / `recording:level` / `recording:result`；
- 结果反馈：成功 / 降级 / 失败的短暂视觉反馈后消失（与 PRD 第 4 章一致）。

### 1.3 范围外

- 语音输入小窗（T-009）；
- 取消录音的状态机逻辑（T-010，本任务只发取消命令）；
- 移动端状态同步（v1.0）。

## 2. 需求依据

- F-INPUT-05：录音时显示音量动效、时长与模式，不抢焦点；
- 产品原则 2（零打扰）：悬浮球不得夺取输入焦点；
- PRD 第 4 章：录音状态与反馈的视觉规范；
- [tech/03](../../tech/03-frontend.md) 3.1 悬浮球约束；
- [tech/09](../../tech/09-cross-platform.md) 9.2.4。

## 3. 技术上下文

- 新建：`src/float/` 页面、后端窗口管理命令（`show_float` / `hide_float` / `move_float`）；
- 复用：T-005 的 `recording:level`；T-001 float 窗口声明；
- 参考截图：`doc/img/语音输入法界面原型截图参考/`（录音反馈样式）。

## 4. 任务步骤

1. 实现 float 页面：Canvas 音量动效（RMS 驱动）、时长计时、模式标签、取消区（拖动到取消区或点击取消按钮）；
2. 后端窗口管理：录音状态迁移到 Recording 时创建 / 显示 float 窗口，结束 / 取消时销毁；
3. 拖动：自定义拖动区域（`data-tauri-drag-region` 或手动 mouse 事件），位置持久化到配置；
4. 不抢焦点验证：录音中焦点保持在原应用（三平台实测；Linux 异常时按 tech/09 降级）；
5. 结果反馈动画（成功 / 失败）后自动销毁；
6. 单元测试：动效参数计算纯函数；手动测试为主。

## 5. 验收标准

- [ ] 录音开始悬浮球出现，显示音量动效、时长、模式；
- [ ] 录音全程原应用焦点不丢失（在文本编辑器中录音，光标不离开）；
- [ ] 悬浮球可拖动，位置下次保持；
- [ ] 录音结束 / 取消后悬浮球消失；
- [ ] 上屏成功 / 失败有不同视觉反馈（对照 PRD 第 4 章）；
- [ ] 悬浮球内无任何可聚焦控件（Tab 无法聚焦）；
- [ ] 三平台手动验证通过（Linux 记录各 WM 行为差异）。

## 6. 测试要求

- Vitest：动效计算函数；
- 三平台手动验证：焦点保持、拖动、反馈动画。

## 7. 完成定义（DoD）

- 验收标准全部勾选；

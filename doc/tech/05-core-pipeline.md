# 第 5 章 核心语音输入链路

> 本章描述"按下快捷键 → 说话 → 文字出现在光标处"的端到端管线设计，是 VT 的核心价值链路。
> 需求依据：F-INPUT-01 ~ 07、F-INPUT-09、F-DICT-01；性能指标 NFR-P-01 ~ P-04。

## 5.1 链路总览

```
用户按键          采集              识别            后处理             上屏
──────► Hotkey ──► AudioService ──► AsrService ──► PostProcess ──► InjectService ──► 目标应用光标
         │              │               │              │                │
         │              │               │              │                │
      悬浮球/小窗 ◄── 事件广播（recording:state / level / result）◄───────┘
```

后处理管线（PostProcess）内部顺序：

```
原始识别文本 → ① 替换词典（F-DICT-01）→ ② 编程口令（F-CODE-02/03/04，v0.5）
            → ③ 场景规则（F-CODE-01/08，v0.5）→ ④ AI 模板（F-AI，可选，v0.5）
            → 最终文本
```

v0.1 只实现 ①；②③④ 在 v0.5 接入，管线预留插件式阶段（Stage）抽象，每阶段可独立开关（产品原则 3：任何自动改写可关闭、可撤回）。

## 5.2 录音状态机

```
                 快捷键按下 / 小窗点击 / 移动端触发(v1.0)
                 ┌──────────────────────────────────────┐
                 ▼                                      │
   ┌──────┐   开始录音   ┌────────────┐  松开按键(按住模式) │
   │ Idle │ ──────────► │ Recording  │ ──────────────┐  │
   └──────┘             └────────────┘               │  │
     ▲  ▲                    │ 取消(Esc/悬浮球)        ▼  │
     │  │                    ▼                    ┌─────────────┐
     │  │              ┌───────────┐  丢弃音频     │ Processing  │ (识别+后处理)
     │  └───────────── │ Cancelled │ ◄──────────  │             │
     │                └───────────┘              └─────────────┘
     │                                                  │
     └──────────────────── 上屏完成 / 失败提示 ◄─────────┘
```

- 状态机由 AudioService 持有（actor 内），每次迁移通过事件广播推给前端（`recording:state`）；
- 按住模式：Release 事件触发结束；切换模式：第二次 Press 触发结束（F-INPUT-02）；
- 取消（F-INPUT-07）：Esc 快捷键 / 悬浮球取消区 / 小窗取消按钮，已采集音频立即丢弃，不进入识别；
- Recording 期间再次触发开始：忽略（同一时刻只有一个录音会话）。

## 5.3 各阶段设计

### 5.3.1 快捷键捕获（HotkeyService）

- 默认快捷键：Alt+R 全平台统一（PRD 3.1.1 规则 1，v1.8；可在设置中修改，F-INPUT-01）；
- 按住 / 切换两种模式（F-INPUT-02），全局生效；
- 注册失败（被占用）→ 提示冲突并引导修改（v0.5 的 F-SYS-03 做系统性冲突检测）；
- 快捷键事件只改变录音状态机，不做任何 UI 操作（UI 由事件驱动）。

### 5.3.2 音频采集（AudioService）

- 采样参数：16 kHz / 单声道 / f32（ASR 引擎输入要求；设备不支持时重采样）；
- **常驻预热**（F-SET-03 可配）：设备常开、流常读，但非录音状态下采样直接丢弃（NFR-PR-07）；预热使启动延迟 ≤150 ms（NFR-P-01）；关闭预热时启动延迟 ≤500 ms（NFR-P-02）；
- 音量电平：采集回调内计算 RMS，节流 50 ms 广播（`recording:level`）驱动悬浮球动效；
- 麦克风异常（拔出 / 独占失败）：状态机回到 Idle，明确提示（NFR-R-03）。

### 5.3.3 本地识别（AsrService）

- 识别在本地完成，录音不出本机（NFR-PR-01/02）；
- 录音结束时把缓冲的音频帧送入推理（`spawn_blocking`），结果为整段文本；
- v0.1 为"说完出整句"模式；v1.x 的"边说边出字"流式预览不在本管线，另行设计；
- 模型管理（F-SET-06）：多模型下载 / 切换 / 删除；模型文件存数据目录，加载前校验完整性。

### 5.3.4 后处理管线（PostProcess）

- 管线 = 有序 Stage 列表，每个 Stage 实现 `fn process(&self, ctx: &mut PipelineContext)`；
- `PipelineContext` 携带：原文、当前场景（v0.5）、目标应用信息、撤回去哪；
- v0.1 唯一 Stage：替换词典（F-DICT-01，长词优先、全词匹配规则见 PRD 3.4 节）；
- 每个 Stage 有独立开关；管线全程可撤回（上屏前文本在内存中，上屏后撤回 = 模拟删除已上屏字符，能力依赖目标应用，尽力而为）。

### 5.3.5 上屏（InjectService）

优先级递减的三条路径：

1. **模拟键入**：逐字符模拟键盘输入（enigo / 平台 API），最通用；
2. **剪贴板粘贴**：目标应用对模拟键入响应异常时，写入剪贴板 + 模拟 `Ctrl/Cmd+V` + 恢复原剪贴板内容；
3. **无焦点兜底**（F-INPUT-09）：检测不到可输入焦点时，文本复制到剪贴板并弹系统通知"已复制，可手动粘贴"。

终端场景默认禁止自动回车（NFR-S-05）：上屏只输入文本，任何情况下不追加 Enter；v0.5 场景识别接入后由场景规则强化。

## 5.4 性能预算

| 指标 | 目标 | 预算分解 |
| --- | --- | --- |
| NFR-P-01 录音启动（预热） | ≤150 ms | 快捷键事件 → 状态迁移 <10 ms；流已开，首帧即录 |
| NFR-P-02 录音启动（非预热） | ≤500 ms | 设备打开 + 流启动 ≤400 ms（cpal 实测校准） |
| NFR-P-03 上屏延迟（≤10 s 语音） | P95 ≤800 ms | 推理 ≤600 ms + 后处理 ≤50 ms + 上屏 ≤150 ms |
| NFR-P-04 上屏延迟（60 s 语音） | P95 ≤2 s | 推理 ≤1.7 s（模型档位相关），其余同上 |

- 预算在 `src-tauri/benches/` 有对应基准测试，发布前在基准机（PRD 第 5 章测量基准）实测；
- 推理耗时是最大变量：模型档位（轻量 / 推荐）在 F-SET-06 中给用户选择，设置页标注各档位预期耗时。

## 5.5 事件流（前端反馈）

| 时刻 | 事件 | 悬浮球 / 小窗表现 |
| --- | --- | --- |
| 录音开始 | `recording:state { Recording, mode }` | 悬浮球出现，音量动效启动 |
| 录音中 | `recording:level`（50 ms 节流） | 波形 / 呼吸动效 |
| 识别中 | `recording:state { Processing }` | 动效切换为"处理中" |
| 上屏成功 | `recording:result { Ok }` | 成功反馈后悬浮球消失 |
| 降级 / 失败 | `recording:result { Degraded/Failed, reason }` | 文字提示 + 错误编号 |

交互细节（动效时长、颜色、位置记忆）以 PRD 第 4 章为准。

## 5.6 异常路径

| 异常 | 处理 |
| --- | --- |
| 录音中麦克风拔出 | 立即结束录音，已采集部分照常识别上屏，双端提示（NFR-R-03） |
| 推理失败（模型损坏等） | 提示 + 错误编号，引导重新下载模型；音频不保存 |
| 上屏失败（无权限 / 目标不响应） | 自动降级到剪贴板路径；仍失败则走无焦点兜底 |
| 录音中超时（上限 5 分钟，可配） | 自动结束并识别已采集部分 |
| 应用崩溃于录音中 | 音频不持久化（隐私），重启后状态为 Idle（NFR-R-02） |

# VibeType v0.1 验收测试手册

> 适用版本：v0.1.9 及之后。目标：完成 roadmap `v0.1-mvp.md` §四发布验收清单中的全部人工 / 真机项。
> 使用方式：逐条执行并在"结果"列记录（通过 / 失败 / 阻塞 + 现象描述）；失败项请附日志页导出文件与复现步骤。
> 默认配置速查：触发键 **Alt+R（左 Alt + R，全平台统一，按住模式）**、取消键 **Esc**、最长录音 5 分钟、悬浮球开、下载源镜像（hf-mirror）、日志双写（文本 + SQLite）。

## 0. 测试环境准备

- [ ] 记录测试平台与版本：OS / 版本号 / 安装包类型（exe / msi / deb / rpm / AppImage）
- [ ] 确认测试机为"干净"环境（无旧版本数据目录），或已备份并删除旧数据目录
- [ ] 准备测试材料：安静环境、可用麦克风、五类目标应用（见 §3）、秒表

**数据目录位置**（应用全部数据均在本机该目录下）：

| 平台 | 路径 |
| --- | --- |
| Windows | `%APPDATA%\com.vibetype.app\` |
| macOS | `~/Library/Application Support/com.vibetype.app/` |
| Linux | `~/.local/share/com.vibetype.app/` |

目录内应能看到：`config.json`、`vibetype.log.YYYY-MM-DD`（文本日志）、`vibetype-logs.sqlite3`（日志库）、`models/`（模型）、`dict.json`（词典）。

## 5. 性能与准确率指标（需记录实测数值）

| 指标 | 目标 | 测量方法 | 实测 |
| --- | --- | --- | --- |
| NFR-P-01/02 首帧延迟 | 预热 ≤150 ms / 非预热 ≤500 ms | 日志埋点 `first_frame_ms`，预热 / 非预热各 10 次取 P95 | 手工没法测试出来，大致可以了 |
| NFR-P-03 全链上屏延迟 | ≤10 秒语音 P95 ≤800 ms | 停止说话到文本出现在目标应用的耗时，20 次取 P95（秒表或埋点） | 大致可以了 |
| NFR-A-01 字准确率 | 普通话通用文本 ≥95% | 朗读 ≥50 句基准测试集，人工比对（字准确率 = 1 − 编辑距离 / 总字数） | 大致可以了 |
| NFR-P-06 空闲内存 | ≤150 MB（不含模型） | 空闲 5 分钟后任务管理器 / `ps` 读进程内存 | 没法手工测试 |
| NFR-P-08 冷启动 | 托盘 ≤3 s / 首次可录音 ≤8 s | §1.7 / §1.8 埋点 | OK |
| NFR-P-09 安装包 | ≤120 MB（不含模型） | 安装包文件大小 | OK |

> 建议基准测试集（≥50 句）覆盖：日常对话、技术词汇（英文混入）、数字与单位、标点口语化句式、常见口令词。样本可后续补充进 `doc/test/`。

## 7. 已知限制（预期行为，请勿当 bug 上报）

1. 鼠标侧键不能作为触发键（E-HOTKEY-002，需平台级钩子）。
2. `float_ball_position=cursor` 降级为底部居中显示。
3. 录音过程中修改快捷键会全量重注册，当轮 Esc 取消失效、下轮恢复。
4. 更新检查不可用（更新服务器未就绪，v1.0 前提供）。
5. 界面仅中文 + 浅色主题（英文界面与深色主题为 v1.0 范围）。
6. 历史记录、编程口令、AI 后处理、移动麦克风、MCP 均不在 v0.1（分别为 v1.0 / v0.5 / v1.0 范围）。

# 第 5 章 非功能需求

> 本章定义产品在性能、准确率、隐私安全、兼容性等方面必须达到的质量标准。指标以“参考配置”为测量基准：近 4 年内发布的主流笔记本电脑，4 核以上处理器、16 GB 内存，无独立显卡要求。

## 5.1 性能

| 编号 | 指标 | 目标值 | 说明 |
| --- | --- | --- | --- |
| NFR-P-01 | 录音启动延迟（麦克风常驻开启） | ≤ 150 毫秒 | 按下快捷键到开始采集声音 |
| NFR-P-02 | 录音启动延迟（麦克风常驻关闭） | ≤ 500 毫秒 | 同上 |
| NFR-P-03 | 纯转录上屏延迟（10 秒以内语音） | P95 ≤ 800 毫秒 | 结束录音到文字上屏 |
| NFR-P-04 | 纯转录上屏延迟（60 秒语音） | P95 ≤ 2 秒 | 同上 |
| NFR-P-05 | AI 模板总耗时 | 本地处理 + 供应商响应时间 + 200 毫秒以内 | 产品自身附加耗时不超过 200 毫秒 |
| NFR-P-06 | 空闲内存占用 | ≤ 150 MB（不含识别模型）；含已加载的推荐模型 ≤ 800 MB | 后台常驻 |
| NFR-P-07 | 空闲处理器占用 | 平均 < 1% | 后台常驻且未录音 |
| NFR-P-08 | 冷启动时间 | ≤ 3 秒出现托盘图标；≤ 8 秒可进行首次录音 | 开机自启场景 |
| NFR-P-09 | 安装包体积 | ≤ 120 MB（不含识别模型） | 模型单独下载 |
| NFR-P-10 | 设置窗口打开 | ≤ 500 毫秒 | 从点击到可交互 |

## 5.2 识别准确率

| 编号 | 指标 | 目标值 | 测量方式 |
| --- | --- | --- | --- |
| NFR-A-01 | 普通话通用文本字准确率 | ≥ 95% | 安静环境、内部通用测试集 |
| NFR-A-02 | 编程术语准确率 | ≥ 90%（启用对应技术词库） | 内部“程序员口述”测试集，不少于 1,000 条，覆盖第 3.2.6 节全部词库 |
| NFR-A-03 | 中英混说句子整句正确率 | ≥ 80% | 同上 |
| NFR-A-04 | 命名风格口令正确率 | ≥ 95% | 口令测试集，每种风格不少于 50 条 |
| NFR-A-05 | 符号口令误转换率 | ≤ 1% | 在不含符号意图的日常语句中被错误转换为符号的比例 |
| NFR-A-06 | 按键口令误触发率 | ≤ 0.5% | 同上 |
| NFR-A-07 | 嘈杂环境（办公室背景噪声）字准确率 | ≥ 88% | 内部噪声测试集 |

> 测试集与评测方法由产品与测试共同维护，每个版本发布前须回归并记录结果，指标不达标的版本不得发布正式版。

## 5.3 隐私

| 编号 | 要求 |
| --- | --- |
| NFR-PR-01 | 语音识别必须在本地完成，录音数据默认不保存、不上传。 |
| NFR-PR-02 | 只有在用户主动配置 AI 供应商并使用对应模板 / 功能时，才可将**文本**发送到该供应商；任何情况下不得发送原始音频到云端（用户主动选择的本地供应商除外）。 |
| NFR-PR-03 | 首次将文本发送到某个云端供应商前，必须弹窗告知“将发送哪些内容到哪个供应商”，用户确认后才发送，并可勾选“不再提示”。 |
| NFR-PR-04 | 默认不收集任何使用数据；匿名统计须用户主动开启，且可在设置中查看上报内容样例、随时关闭。 |
| NFR-PR-05 | 历史记录、统计、词典、模板等数据仅保存在本机，提供一键清除全部个人数据的入口（位于“通用 › 隐私与安全”底部）。 |
| NFR-PR-06 | 自动检查更新只发送当前版本号、操作系统类型与架构，不发送任何个人信息。 |
| NFR-PR-07 | 麦克风只在用户按下录音快捷键 / 按钮期间采集声音；麦克风常驻（预热）状态下不得采集或保存任何声音。 |
| NFR-PR-08 | 卸载产品时提示是否同时删除本地数据（模型、词典、历史、设置）。 |

## 5.4 安全

| 编号 | 要求 |
| --- | --- |
| NFR-S-01 | API Key、MCP 访问令牌必须加密保存，优先使用操作系统提供的凭据保护能力；界面默认掩码显示。 |
| NFR-S-02 | 日志、导出日志、备份文件（未选择包含密钥时）中不得出现 API Key、访问令牌、识别文本、提示词内容、选中文本与剪贴板内容。 |
| NFR-S-03 | 敏感信息检测须覆盖：常见云服务与大模型平台的密钥格式、私钥文件内容、密码类赋值语句、手机号、身份证号、银行卡号、邮箱、内网地址；检测在本地完成。 |
| NFR-S-04 | MCP 服务默认关闭，仅监听本机；开启访问令牌后，未携带正确令牌的调用一律拒绝并记录。 |
| NFR-S-05 | 终端场景默认禁止自动回车，任何口令或词典规则不得绕过该保护（除非用户在场景规则中显式开启）。 |
| NFR-S-06 | 产品自身的更新包须经过签名校验，校验失败不得安装。 |
| NFR-S-07 | 导入的词典、模板、备份文件须进行格式校验，异常文件不得导致产品崩溃或执行任何内容。 |

## 5.5 兼容性

### 5.5.1 操作系统

| 平台 | 支持版本 | 说明 |
| --- | --- | --- |
| Windows | Windows 10（22H2）及以上、Windows 11 | x64 与 ARM64 |
| macOS | macOS 13 及以上 | Apple 芯片与 Intel 芯片；需要麦克风与辅助功能权限 |
| Linux | Ubuntu 22.04+、Debian 12+、Fedora 39+ 等主流发行版 | X11 完整支持；Wayland 下全局快捷键与模拟输入受桌面环境限制，提供替代方案（如通过桌面环境自定义快捷键触发、仅剪贴板模式），并在常见问题中说明 |

### 5.5.2 目标应用兼容

正式版发布前，以下类别的应用必须通过“上屏正确、场景识别正确、口令生效”的兼容性测试：

| 类别 | 代表应用 |
| --- | --- |
| IDE / 编辑器 | VS Code、JetBrains 系列 IDE、Cursor、Zed、Sublime Text、Vim / Neovim（终端内） |
| 终端 | Windows Terminal、PowerShell、macOS 终端、iTerm2、GNOME Terminal、Konsole、IDE 内置终端 |
| AI 对话 | IDE 内置 AI 对话面板、命令行编程智能体、浏览器中的主流大模型对话网页 |
| 浏览器 | Chrome、Edge、Firefox、Safari |
| 沟通 / 文档 | 飞书、钉钉、企业微信、微信、Slack、Notion、Obsidian、Typora |

### 5.5.3 硬件

- 麦克风：内置麦克风、有线 / 蓝牙耳机麦克风、USB 麦克风；设备热插拔时自动处理。
- 最低配置：双核处理器、8 GB 内存（可使用轻量识别模型，性能指标按最低配置另行标注）。

## 5.6 可靠性

| 编号 | 要求 |
| --- | --- |
| NFR-R-01 | 连续运行 7 天无崩溃、无明显内存增长（增长不超过 50 MB）。 |
| NFR-R-02 | 崩溃后自动重启后台服务，用户设置与未保存以外的数据不丢失。 |
| NFR-R-03 | 麦克风断开、切换、被其他软件独占时给出明确提示，不导致产品无响应。 |
| NFR-R-04 | 网络中断时，云端 AI 相关功能降级，本地语音输入不受影响。 |
| NFR-R-05 | 设置与词典的保存须保证完整性：保存过程中断电或崩溃，不得产生损坏的配置；损坏时自动回退到最近一次有效配置。 |
| NFR-R-06 | 版本升级须保留并兼容用户已有的全部配置与数据。 |

## 5.7 可维护性与可观测性

1. 应用日志按天滚动，本地最多保留 7 天；日志级别可在“关于”中切换为“详细”，用于问题排查，24 小时后自动恢复为“普通”。
2. “导出日志”生成单个文件，包含操作系统版本、产品版本、模型信息、最近 1,000 行日志，自动脱敏。
3. 所有错误提示附带简短错误编号，便于在常见问题与反馈中对应。

## 5.8 国际化与本地化

1. 界面语言首发：简体中文、English；v1.x 增加繁體中文。
2. 语言切换即时生效，无需重启。
3. 识别语言与界面语言相互独立。

## 5.9 合规

1. 遵守《中华人民共和国个人信息保护法》《数据安全法》以及欧盟《通用数据保护条例》（GDPR）等适用法律的基本原则：最小必要、告知同意、用户可控。
2. 产品内提供隐私说明，清晰列出：采集哪些数据（默认无）、在什么情况下向第三方发送什么数据、用户如何删除数据。
3. 产品以开源许可证发布，第三方开源组件须在“关于 › 第三方开源组件声明”中列明名称、版本与许可证，许可证须与本项目许可证兼容。
4. 预置 AI 供应商仅提供接口地址的便捷配置，不代表与这些服务存在合作关系；在“API Key 申请指南”中提示用户遵守各服务条款。

# 第 6 章 版本规划与度量

## 6.2 度量指标

由于产品坚持“默认不收集数据”，度量依赖三类来源：**用户自愿开启的匿名统计**、**开源社区数据**、**定期用户调研**。

### 6.2.1 北极星指标

**周人均语音上屏字数**（自愿开启匿名统计的活跃用户）—— 衡量产品是否真正替代了键盘输入。v1.0 发布 6 个月后目标：≥ 5,000 字 / 人 / 周。

### 6.2.2 指标体系

| 维度 | 指标 | 来源 | 目标（v1.0 + 6 个月） |
| --- | --- | --- | --- |
| 规模 | 安装量（下载量） | 发布页统计 | ≥ 50,000 |
| 规模 | 仓库 Star 数 | 代码托管平台 | ≥ 5,000 |
| 活跃 | 周活跃比例 | 匿名统计 | ≥ 40% |
| 留存 | 7 日 / 30 日留存 | 匿名统计 | ≥ 50% / ≥ 30% |
| 深度 | 使用编程口令的用户占比 | 匿名统计 | ≥ 35% |
| 深度 | 使用 AI 模板的用户占比 | 匿名统计 | ≥ 30% |
| 深度 | 启用 MCP 服务的用户占比 | 匿名统计 | ≥ 10% |
| 质量 | AI 降级（超时 / 失败）比例 | 匿名统计 | ≤ 5% |
| 质量 | “删除上一句”使用率（识别不满意的间接信号） | 匿名统计 | ≤ 8% |
| 满意度 | NPS | 季度问卷 | ≥ 40 |
| 社区 | 外部贡献者数量 / 首次响应 Issue 时长 | 代码托管平台 | ≥ 30 人 / ≤ 48 小时 |

### 6.2.3 匿名统计上报范围（须在产品中公开）

- 允许：产品版本、操作系统类型、功能使用次数（录音次数、口令使用次数、模板使用次数）、上屏字数（仅数量）、降级次数、崩溃次数；
- 禁止：任何识别文本、提示词、音频、应用窗口标题、文件路径、词典内容、API Key、IP 之外的设备标识。

## 6.3 风险与应对

| 编号 | 风险 | 可能性 | 影响 | 应对措施 |
| --- | --- | --- | --- | --- |
| R-01 | 本地模型在中英混说与术语上准确率不达标 | 中 | 高 | 技术词库 + 专有名词 + 项目术语多层校正；建立程序员口述测试集持续评测；提供多个模型供选择 |
| R-02 | 平台限制（Wayland、macOS 权限）导致部分功能不可用 | 高 | 中 | 首次引导清晰说明权限；Wayland 提供替代方案并在常见问题中说明 |
| R-03 | 符号 / 按键口令误触发，造成用户不信任 | 中 | 高 | “宁可漏转不可错转”原则；高风险按键默认关闭；“删除上一句”兜底；误触发率作为发布门槛 |
| R-04 | 用户担心隐私，不敢使用 AI 功能 | 中 | 中 | 本地供应商一等公民；敏感信息检测；首次外发明示；开源可审计 |
| R-05 | 第三方 AI 服务接口变更或不稳定 | 中 | 中 | 统一使用兼容协议；连接测试与可读错误；超时降级保证基本可用 |
| R-06 | 快捷键与用户其他软件冲突 | 中 | 中 | 默认右侧修饰键；冲突检测；支持鼠标侧键 |
| R-07 | 参考原型带来的品牌与知识产权风险 | 低 | 高 | 产品名称、图标、视觉、文案独立设计；参考截图仅用于内部设计参考；发布前进行商标检索 |

> 备注（2026-10-09，PRD v1.1）：原风险 R-08“音视频转录被用于未经同意的录音”随“音视频转录”功能一并移除——该功能已决策不再提供（详见第 1 章 1.7.2 节），对应风险不复存在。

## 6.5 术语表

| 术语 | 解释 |
| --- | --- |
| 上屏 | 将最终文字输入到当前应用光标所在位置 |
| 纯转录 | 只做语音识别与本地文本处理，不经过 AI 处理 |
| 场景 | 根据当前应用自动匹配的一组输出规则，如编码场景、终端场景 |
| 编程口令 | 用于输出命名风格、符号、按键的固定说法，如“驼峰”“左括号”“换行” |
| 技术词库 | 产品内置的按技术方向划分的术语集合 |
| 专有名词 | 用户维护的“标准写法 + 读音别名”，按发音校正识别结果 |
| 替换词典 | 用户维护的“错误词 → 正确词”精确替换规则 |
| 提示词模板 | 定义 AI 如何处理识别文本的指令，可绑定快捷键、供应商与模型 |
| AI 供应商 | 提供大模型服务的平台或本地软件，通过接口地址与 API Key 接入 |
| MCP | 模型上下文协议（Model Context Protocol），让 AI 智能体以标准方式调用外部工具 |
| 语音提问 | 通过 MCP，由 AI 智能体发起问题、用户语音回答的交互 |
| 降级 | AI 处理超时或失败时，改为上屏本地识别结果 |
| 麦克风常驻 | 保持麦克风设备预热以减少启动延迟，但不采集声音 |
| Vibe Coding | 以自然语言与 AI 协作为主要方式的编程工作流 |

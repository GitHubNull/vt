# 第 4 章 交互与视觉设计

> 本章描述交互原则、窗口布局、状态反馈与视觉规范，供设计师输出高保真稿使用。所有数值为设计目标值，设计稿可在评审后微调。

## 4.1 交互设计原则

1. **一键直达**：最常用的动作（说话 → 上屏）只需要一个快捷键，不需要打开任何窗口。
2. **不抢焦点**：悬浮球、提示、语音提问卡片均不得夺走当前输入框的焦点。
3. **状态可感知**：录音中、识别中、AI 处理中、完成、失败，每个状态都有可视化反馈，用户永远知道“现在发生了什么”。
4. **可撤回**：自动改写（口令、替换、AI）都可以通过“删除上一句”或历史记录恢复原始结果。
5. **渐进披露**：新手只需知道一个快捷键；编程口令、模板、场景规则等进阶能力通过引导、速查卡、常见问题逐步发现。
6. **设置即时生效**：开关类设置切换后立即生效；表单类设置（词典、模板、供应商）需要点击“保存”，离开时提示未保存。

## 4.2 窗口与布局

### 4.2.1 设置窗口

- 默认尺寸约 1100 × 800（逻辑像素），最小 900 × 640，可调整大小，记住上次尺寸与位置。
- 标题栏：左侧产品图标与名称，右侧最小化、关闭；关闭仅隐藏窗口，不退出产品。
- 三栏布局（参考截图 21-32-16、21-34-15）：

| 区域 | 宽度 | 内容 |
| --- | --- | --- |
| 一级导航（左栏） | 约 280 | 顶部返回箭头（回到语音输入小窗）；导航项：图标 + 文字；选中项浅灰底 + 左侧主色竖条 |
| 二级导航（中栏） | 约 300 | 顶部模块标题 + 副标题；导航项选中态同上 |
| 内容区（右栏） | 自适应 | 页面标题、说明、操作按钮区、内容列表；内容超出时**仅内容区滚动** |

- 无二级导航的模块（我的、统计、常见问题、关于）内容区直接占满中栏与右栏；"通用"模块含二级导航（界面 / 输入与录音 / 文本输出 / 录音环境 / 系统与数据 / 模型管理）。
- 窗口变窄（小于 1000）时，中栏收起为内容区顶部的标签页。

### 4.2.2 语音输入小窗

- 尺寸约 260 × 330，不可调整大小，可拖动（参考截图 21-38-03）。
- 自上而下：标题栏 → 圆形麦克风按钮（直径约 88，浅灰底）→ 提示文案 → 场景标签 → 最近结果（单行）→ 底部两个方形按钮（历史记录、设置）。

### 4.2.3 录音悬浮球

- 胶囊形，高约 40，宽度随内容自适应（约 120–280）。
- 内容：状态图标 / 波形动效 + 时长 + 模式标签（纯转录 / 模板名）+ 取消按钮。
- 默认出现在光标下方偏右，距离约 24；靠近屏幕边缘时自动翻转方向，避免超出屏幕。

## 4.3 录音状态设计

| 状态 | 触发 | 悬浮球表现 | 托盘图标 | 小窗麦克风按钮 |
| --- | --- | --- | --- | --- |
| 空闲 | 默认 | 不显示 | 常规 | 浅灰底麦克风图标 |
| 录音中 | 按下快捷键 | 主色波形随音量跳动 + 计时 | 红点 | 主色底，呼吸动效 |
| 即将超时 | 距离最长录音时长 10 秒 | 计时变为倒计时，橙色 | 红点 | 同上 |
| 识别中 | 结束录音 | 三点加载动效，“识别中” | 处理中动效 | 加载动效 |
| AI 处理中 | 使用模板且识别完成 | 模板名 + 加载动效 + 剩余超时进度条 | 处理中动效 | 加载动效 |
| 完成 | 上屏成功 | 绿色对勾，0.8 秒后淡出 | 常规 | 恢复空闲 |
| 已复制 | 无焦点兜底 | “已复制到剪贴板”，1.5 秒后淡出 | 常规 | 恢复空闲 |
| 降级 | AI 超时 / 失败 | 黄色提示“AI 超时，已输入原始结果”，2 秒后淡出 | 常规 | 恢复空闲 |
| 安全提醒 | 终端阻止回车 / 高风险命令 | 橙色或红色提示条，停留 4 秒，可点击“了解” | 常规 | 恢复空闲 |
| 失败 | 无麦克风、模型缺失等 | 红色提示 + “去处理”按钮 | 黄色感叹号 | 显示错误提示 |
| 已取消 | 按 Esc | “已取消”，0.5 秒后淡出 | 常规 | 恢复空闲 |

## 4.5 视觉规范

### 4.5.1 色彩

| 用途 | 浅色主题 | 说明 |
| --- | --- | --- |
| 主色 | 明亮蓝（接近原型按钮蓝） | 主按钮、开关、选中竖条、链接 |
| 背景 | 极浅灰（窗口底）/ 白色（卡片） | 层次靠底色区分，少用阴影 |
| 文字 | 深灰（标题）/ 中灰（说明）/ 浅灰（占位） | 正文与背景对比度不低于 4.5 : 1 |
| 成功 | 绿色 | 运行中、完成 |
| 警告 | 橙色 | 即将超时、安全提醒 |
| 危险 | 红色 | 失败、删除、高风险命令 |

- 深色主题：背景使用深灰而非纯黑，主色适当提亮，保证对比度达标。
- 产品主色与图标须独立设计，不得直接使用参考原型的品牌资产。

### 4.5.2 字体

- 中文使用系统默认无衬线字体；英文与数字同样使用系统 UI 字体。
- **模型标识、接口地址、服务地址、快捷键、口令输出示例使用等宽字体**（参考截图 21-35-19 中模型标识的等宽小字），方便程序员辨认大小写与符号。
- 字号层级：页面标题 18–20；分组 / 卡片标题 15–16；正文 14；说明 12–13。

### 4.5.3 图标

- 线性图标，线宽统一；一级导航图标与文字垂直居中对齐。
- 新增“编程”导航图标建议使用“尖括号 + 声波”的组合意象。

### 4.5.4 动效

- 悬浮球出现 / 消失：150 毫秒淡入淡出 + 轻微缩放。
- 波形：随实时音量变化，静音时保持低幅度呼吸，提示“正在听”。
- 卡片展开 / 折叠：200 毫秒高度过渡。
- 尊重系统“减少动态效果”设置，开启时以静态图标替代动效。

## 4.7 文案规范

1. 称呼用户使用“你”；语气简洁、专业、友好，避免感叹号堆砌。
2. 专有名词保持标准写法：MCP、AI、API Key、Prompt 等。
3. 中英文之间加空格（如“启用 MCP 服务”），与产品自身的输出规范一致。
4. 错误提示须包含“发生了什么 + 怎么解决”，例如“麦克风不可用：未检测到输入设备。请连接麦克风或在‘通用 › 录音环境’中选择其他设备”。

## 4.8 可访问性

1. 所有功能均可通过键盘操作，焦点顺序与视觉顺序一致，焦点框清晰可见。
2. 所有图标按钮提供无障碍名称（如“删除规则：f二”）。
3. 状态变化（录音开始、完成、失败）同时提供视觉与可选的声音反馈，不仅依赖颜色。
4. 支持系统字体缩放至 200% 时布局不破损。

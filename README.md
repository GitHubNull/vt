# VibeType（码语）· VT

> 面向程序员的隐私优先 AI 语音输入法 —— 说得出，就打得对。

VibeType（中文名：码语，项目代号 VT）是一款专为程序员设计的桌面语音输入产品：在任何应用的光标处，把你说的话准确地变成程序员想要的文字——术语正确、命名规范、符号到位，并可一键交给 AI 整理成结构化的提示词、Commit 信息或技术文档。

## 为什么需要它

- **通用输入法不懂技术**：“Redis”变成“瑞迪斯”，“useState”变成“优斯 state”；
- **中英混说一塌糊涂**：大小写、空格、标点全靠手动修；
- **代码无法口述**：驼峰、蛇形、常量、括号、箭头……说不出来；
- **隐私不放心**：口述内容常涉及公司代码与业务，不该上云；
- **AI 编程时代**：程序员每天要向 AI 描述大量需求，键盘成了瓶颈。

## 核心能力

| 能力 | 说明 |
| --- | --- |
| 本地离线识别 | 语音识别默认在本地完成，录音不出本机 |
| 技术词库 | 按技术栈启用术语包：Java、前端、Python、Go、Rust、云原生、数据库、AI 大模型…… |
| 编程口令 | 说“驼峰 user name”得到 userName；说“左括号”“箭头”“换行”直接输出符号与按键 |
| 场景感知 | 自动识别 IDE / 终端 / AI 对话 / 文档沟通场景，切换标点、空格、口令规则 |
| 终端安全保护 | 终端中只上屏不执行，危险命令醒目提醒，杜绝“识别错误直接回车” |
| AI 提示词模板 | 内置结构化 Prompt、Commit 信息、Code Review 评论、技术翻译等模板，可绑定独立快捷键 |
| 多 AI 供应商 | 预置通义千问、DeepSeek、智谱 AI、豆包、硅基流动、Ollama、LM Studio、Kimi、Gemini、OpenAI 等，支持本地大模型 |
| MCP 服务 | 开放 MCP 接口，AI 编程智能体可向用户发起语音提问、查询与建议专有名词 |
| 移动麦克风 | 手机扫码配对（二维码 + 一次性随机码）或局域网 mDNS 发现，即可把手机变成电脑的无线麦克风；支持手动连接码与 USB 有线连接兜底。移动客户端为独立 Git 子项目 |
| 词典系统 | 替换词典（错误词 → 正确词）与专有名词（标准写法 + 读音别名），支持导入导出 |
| 隐私与安全 | 敏感信息检测（密钥、私钥、手机号等）外发前自动打码；默认零数据收集 |

> **范围说明**：本产品聚焦“实时语音输入”唯一核心场景，**不提供音视频文件转录（会议录音转文字、字幕导出等）能力**，目前及未来较长一段时间内均无此计划（详见 PRD 第 1 章范围边界）。

## 产品形态

- **语音输入小窗**：轻量主窗口，一个麦克风按钮即可开始；
- **录音悬浮球**：录音时显示音量动效、时长与当前模式，不抢焦点；
- **设置窗口**：词典、编程、AI、通用、统计等模块的三栏式设置中心；
- **系统托盘**：常驻后台，一个快捷键（默认右 Alt）完成“说—转—上屏”。

## 支持平台

- **桌面端（本仓库）**：Windows 10+（x64 / ARM64）、macOS 13+（Apple Silicon / Intel）、主流 Linux 发行版（X11 完整支持，Wayland 提供替代方案）。
- **移动客户端（独立子项目 `vt-mobile`）**：Android 10+、iOS 16+，作为桌面端的无线 / 有线麦克风与遥控录音设备（识别仍在桌面端本地完成）。
